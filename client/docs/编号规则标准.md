# 跨境物流系统编号规则标准 v2.0（行业标准版）

## 一、编号设计原则

参考国际物流行业标准（IATA、IMO、ISO等）和国内主流货代系统：

1. **国际通用性**：符合国际物流编码规范
2. **业务可识别**：从编号即可识别业务类型、时间、地点
3. **系统兼容性**：便于与第三方系统对接
4. **防重复性**：通过多维度组合确保唯一性

---

## 二、核心编号规则

### 1️⃣ 主订单号 (Master Order No / MAWB类似)

**格式**: `{公司代码}{年份后2位}{月份}{日期}{流水号5位}`

**完整格式**: `MMYY-YYYYMMDD-XXXXX`

- **公司代码**: `MM` (2位，如 `GZ`=广州喵喵, `SZ`=深圳分公司)
- **年份**: `YY` (2位)
- **日期**: `YYYYMMDD` (8位完整日期)
- **流水号**: `XXXXX` (5位，每日从00001开始)

**示例**:
```
GZ24-20240115-00001  (广州公司2024年1月15日第1单)
GZ24-20240115-00099  (广州公司2024年1月15日第99单)
SZ24-20240115-00001  (深圳公司2024年1月15日第1单)
```

**说明**: 参考航空主运单号(MAWB)格式，便于国际业务对接

---

### 2️⃣ 子订单号 (House Order No / HAWB类似)

**格式**: `{主订单号}-{批次}{运输方式}`

**完整格式**: `MMYY-YYYYMMDD-XXXXX-{批次}{方式}`

- **批次**: `01-99` (2位数字)
- **运输方式**:
  - `S` = Sea (海运)
  - `A` = Air (空运)
  - `E` = Express (快递)
  - `T` = Truck (陆运)

**示例**:
```
GZ24-20240115-00001-01S  (主单00001的第1批次海运)
GZ24-20240115-00001-02A  (主单00001的第2批次空运)
GZ24-20240115-00001-03E  (主单00001的第3批次快递)
```

**说明**: 参考航空分运单号(HAWB)格式，清晰标识运输方式

---

### 3️⃣ 任务号 (Job No / Shipment Reference)

**格式**: `JOB{运输方式}{起运港}{目的港}{年月日}{流水号}`

**完整格式**: `JOB-{MODE}-{ORIGIN}-{DEST}-YYMMDD-XXX`

- **运输方式**:
  - `SEA` = 海运整柜(FCL)
  - `LCL` = 海运拼箱
  - `AIR` = 空运
  - `EXP` = 快递
  - `TRK` = 陆运
- **起运港**: 3位IATA/UN-LOCODE代码
- **目的港**: 3位IATA/UN-LOCODE代码
- **日期**: `YYMMDD` (6位)
- **流水号**: `XXX` (3位)

**示例**:
```
JOB-SEA-SZX-LOS-240115-001  (深圳到拉各斯海运，2024/1/15第1个任务)
JOB-AIR-CAN-ACC-240118-001  (广州到阿克拉空运，2024/1/18第1个任务)
JOB-LCL-SHA-LOS-240120-001  (上海到拉各斯拼箱，2024/1/20第1个任务)
```

**常用港口代码**:
- 中国: SZX(深圳), CAN(广州), SHA(上海), PEK(北京)
- 尼日利亚: LOS(拉各斯), PHC(哈科特港)
- 加纳: ACC(阿克拉), TML(特马)
- 美国: LAX(洛杉矶), JFK(纽约), ORD(芝加哥)

**说明**: 参考国际货代行业标准，使用IATA/UN-LOCODE港口代码

---

### 4️⃣ 集装箱号 (Container No)

**标准集装箱号格式**: 遵循ISO 6346国际标准

**格式**: `{箱主代码4位}{设备识别码1位}{序列号6位}{校验码1位}`

**自有箱编号**: `MMCU{序列号6位}{校验码1位}`
- **箱主代码**: `MMCU` (喵喵Container Unit)
- **序列号**: `000001-999999`
- **校验码**: 1位数字（按ISO 6346算法计算）

**示例**:
```
MMCU0000017  (自有集装箱)
MMCU0012345  (自有集装箱)
TEMU1234567  (租用集装箱，保持原编号)
```

**内部简化编号**: `{仓库}{年份}{序号}`
```
GZ24-C001  (广州仓2024年第1个集装箱)
SZ24-C099  (深圳仓2024年第99个集装箱)
```

**说明**: 标准集装箱号全球通用，便于海关、港口、船公司识别

---

### 5️⃣ 空运托盘号 (ULD Number)

**格式**: `{ULD类型3位}{序列号5位}{航空公司2位}`

**示例**:
```
AKE12345MM  (AKE型托盘，序列号12345，喵喵航空代码MM)
PMC00001MM  (PMC型托盘)
```

**内部简化编号**:
```
GZ24-P001  (广州仓2024年第1个托盘)
SZ24-P099  (深圳仓2024年第99个托盘)
```

**说明**: 参考IATA ULD编号标准

---

### 6️⃣ 客户编号 (Customer ID)

**格式**: `{国家2位}{城市2位}{年份2位}{流水号4位}`

**完整格式**: `CN-{CITY}-YY-XXXX`

- **国家**: `CN`(中国), `NG`(尼日利亚), `GH`(加纳), `US`(美国)
- **城市**: `SZ`(深圳), `GZ`(广州), `SH`(上海), `BJ`(北京)
- **年份**: 注册年份后2位
- **流水号**: `0001-9999`

**示例**:
```
CN-SZ-24-0001  (中国深圳2024年第1个客户)
CN-GZ-24-0099  (中国广州2024年第99个客户)
NG-LOS-24-0001 (尼日利亚拉各斯2024年第1个客户)
```

**客户简码 (Customer Code)**: 用于日常快速识别
```
SZ240001  (深圳24年第1个客户)
GZ240099  (广州24年第99个客户)
```

**说明**: 包含地域和时间信息，便于客户管理和统计

---

### 7️⃣ 提单号 (Bill of Lading No)

**海运提单 (B/L)格式**: `{船公司代码}{年份}{流水号8位}`

**示例**:
```
MMBL24000001  (喵喵海运2024年第1个提单)
COSCBL240001  (COSCO提单，保持原格式)
```

**空运提单 (AWB)格式**: `{航空公司3位}-{主单号8位}`

**示例**:
```
999-12345678  (航空公司代码999的主运单)
```

**说明**: 提单号是货物所有权凭证，需严格管理

---

### 8️⃣ 仓库编号 (Warehouse Code)

**格式**: `WH-{国家}-{城市}-{类型}-{序号}`

- **国家**: `CN`, `NG`, `GH`, `US`
- **城市**: `SZ`, `GZ`, `SH`, `LOS`, `ACC`
- **类型**:
  - `O` = Origin (起运国仓)
  - `D` = Destination (目的国仓)
  - `T` = Transit (中转仓)
- **序号**: `01-99`

**示例**:
```
WH-CN-SZ-O-01  (中国深圳起运仓1号)
WH-CN-GZ-O-01  (中国广州起运仓1号)
WH-NG-LOS-D-01 (尼日利亚拉各斯目的仓1号)
WH-GH-ACC-D-01 (加纳阿克拉目的仓1号)
```

**说明**: 清晰标识仓库位置和功能

---

### 9️⃣ 发票号 (Invoice No)

**格式**: `INV-{公司代码}-YYYY-XXXXXX`

- **公司代码**: `GZ`, `SZ`, `SH`
- **年份**: `YYYY` (4位完整年份)
- **流水号**: `XXXXXX` (6位，年度重置)

**示例**:
```
INV-GZ-2024-000001  (广州公司2024年第1张发票)
INV-SZ-2024-000099  (深圳公司2024年第99张发票)
```

**说明**: 符合财务管理和税务要求

---

### 🔟 报关单号 (Customs Declaration No)

**格式**: `{海关代码4位}{年份4位}{流水号8位}`

**示例**:
```
5130202400000001  (深圳海关2024年第1个报关单)
0100202400000001  (北京海关2024年第1个报关单)
```

**内部跟踪号**: `CUS-{出口/进口}-YYYYMMDD-XXXXX`

**示例**:
```
CUS-EXP-20240115-00001  (出口报关)
CUS-IMP-20240120-00001  (进口报关)
```

**说明**: 报关单号由海关系统生成，内部跟踪号用于管理

## 三、辅助编号

### 入库单号 (Inbound Receipt)
```
IBD-{仓库代码}-YYYYMMDD-XXXX
示例: IBD-WH-CN-SZ-O-01-20240115-0001
```

### 出库单号 (Outbound Delivery)
```
OBD-{仓库代码}-YYYYMMDD-XXXX
示例: OBD-WH-CN-SZ-O-01-20240115-0001
```

### 配送单号 (Delivery Order)
```
DEL-{目的国}-{城市}-YYYYMMDD-XXXX
示例: DEL-NG-LOS-20240120-0001
```

### 费用单号 (Charge Note)
```
CHG-{费用类型}-YYYYMMDD-XXXXX
示例: CHG-FRT-20240115-00001  (运费)
示例: CHG-THC-20240115-00001  (码头操作费)
```
