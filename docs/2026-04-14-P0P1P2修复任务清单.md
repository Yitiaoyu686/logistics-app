### ⬜ P0-1: 快递入库 — 费用明细 + 货物类别
**文件**：`app/app/task/inbound.tsx`
**Web 参照**：`/Users/mac/Documents/code/111_0410/client/src/pages/wms/origin/InboundDetailDrawer.tsx`

**需要补充的能力**：
1. **费用 Section**（在量方/照片之后）
   - 自动运费：`max(actualWeight, volumeWeight) × 单价 × 汇率`
   - 海运：单价 12 USD/kg，最低 50 USD，体积系数 /5000
   - 空运：单价 55 USD/kg，最低 150 USD,体积系数 /6000
   - 「+ 添加费用」按钮 → 弹窗表单（费用类型/币种/单价/数量/汇率/金额/备注）
   - 费用列表（可删除）
   - 合计 USD
2. **货物类别下拉**（普货/敏感/电池/液体/粉末/食品/其它）
3. **FEE_TYPE_OPTIONS**：FREIGHT/操作费/关税/仓储/派送/报关/加固/上门取件/到门费用
4. **CURRENCY**：USD / CNY / NGN

**后端接口**：已有 `POST /api/v2/wms/inbound/:id/fees`（需复核字段）

**关键代码片段**（从 Web 移植）：
```typescript
const volumeWeight = (l*w*h) / (serviceType === 'EXPRESS' ? 6000 : 5000);
const chargeWeight = Math.max(actualWeight, volumeWeight);
const unitRate = serviceType === 'EXPRESS' ? 55 : 12;
const minCharge = serviceType === 'EXPRESS' ? 150 : 50;
const freightAmount = Math.max(chargeWeight * unitRate, minCharge);
```
