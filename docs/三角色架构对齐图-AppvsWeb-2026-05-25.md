## SALES（销售）

### 页面全景

```
Web (6页)                              App (7页)
────────────────────────────────────────────────────────────
```

|---|---|---|
| 统计卡片(4-6个指标Tag) | ❌ 无 | 🔴 |

**App任务卡片详情:**

| 卡片 | 触发条件 | 按钮 | 跳转 |
|---|---|---|---|
| 货到未收款 | 货已到+未付/部分付款 | 无按钮(点击卡片) | `/task/order-detail` |

#### 7. SALES差异汇总

| 级别 | 差异 | 影响 |
|---|---|---|
| 🔴 | **缺公海池认领审核**(无ADMIN/OPS_CN角色) | 认领流程无法闭环 |
| 🔴 | **缺订单编辑/审核/暂停/恢复** | 订单管理不完整 |
| 🔴 | **缺高级筛选**(日期/国家/城市/站点) | 大量订单时查找困难 |
| 🔴 | **缺客户删除** | 无清理能力 |
| 🟡 | **缺客户详情内联编辑** | 需跳转编辑页 |
| 🟡 | **缺客户交易数据/跟进记录** | 客户分析弱 |
| 🟡 | **报价数据源不同**(API vs 本地算法) | 价格可能不一致 |
| 🟢 | **App有快捷拨打/短信/下单/试算** | Web无此便捷功能 |

## 全局差异分类汇总

### App优于Web的功能
1. **扫码体验**:连续扫码、防重、Toast反馈、双向扫描(装箱)
2. **照片存证**:入库拍照、配送签收拍照、配送失败拍照
3. **配送签收**:签收人+照片+COD收款
4. **自提核销**:取件码验证+SMS预览
5. **DPN一键入库**:跳过逐项核对
6. **快捷拨打/短信**:客户详情直接拨号
7. **物流轨迹可视化**:订单详情10步时间线

### Web优于App的功能
1. **统计卡片**:几乎所有页面都有统计数据
2. **高级筛选**:日期/支付/站点等组合筛选
3. **详情Drawer**:调拨/退运/DPN等都有完整详情页
4. **内联编辑**:库存/客户详情支持直接编辑
5. **批量操作**:库存批量通知等
6. **Popover**:DPN列表悬停查看运单明细
7. **客户删除/无单编辑/无单退回**

### 架构差异
1. Web:状态驱动路由(activeMenuKey+activeTabKey),1个SPA切换
2. App:文件路由(expo-router),每页独立文件,深层Link跳转
3. Web:Modal/Drawer堆叠(App内)
4. App:Alert对话框为主(少量BottomSheet Modal),无Drawer概念
