## 模块总览

### 我的喵喵（业务员/销售端）
- **订单列表** — 多级筛选（国家→城市→站点）、搜索、列表展示、订单详情（含物流状态、初始/实际信息、应收明细）
- **我的客户** — 客户管理、客户信息维护
- **应收列表/应收管理** — 应收账款列表、应收明细管理
- **TTC管理** — TTC（运输单元）管理、查看、添加订单
- **备用金账户** — 备用金充值、消费记录
- **退赔管理** — 退赔申请、审批流程

### 起运国办（起运国办公/调度端）
- **创建任务** — 选择运输方式/承运人，创建运输任务
- **出口跟踪** — 出口物流状态跟踪（到达口岸/出口申报/海关查验/放行/离境）
- **JOB成本录入POL** — JOB维度的成本录入（运费/报关费/杂费等）
- **应收管理** — 起运国维度的应收管理（变更/确认支付/审核）
- **订单费用** — 订单维度的费用录入与查看（含运价表）

### 起运国仓（起运国仓库端）
- **货物入库** — 货物到仓扫描入库，录入重量/尺寸
- **JOB入库** — JOB维度的入库管理
- **库存列表** — 仓库库存查看、操作（取消/退运等）
- **集中装箱** — 货物打包装箱，关联集装号
- **执行任务** — 执行调拨/运输任务
- **取消订单** — 订单取消处理
- **未知运单** — 无订单快递的处理，可创建订单并绑定客户

### 到达国办（目的国办公/调度端）
- **JOB成本录入POD** — 目的国JOB成本录入
- **DPN成本A/B** — DPN（配送单）成本管理，两种展示方案
- **创建DPN** — 创建配送单，选择配送方式/承运人
- **应收管理** — 目的国维度的应收管理
- **进口跟踪** — 进口物流状态跟踪（到达机场/进口申报/海关查验/放行/入库）
- **通知客户** — 货物到达后通知客户取件/配送

### 到达国仓（目的国仓库端）
- **货物入库** — 目的国货物到仓入库
- **DPN货物入库** — DPN维度的入库管理
- **库存列表** — 目的国仓库库存
- **执行DPN任务** — 执行配送任务
- **配送列表** — 配送单列表，跟踪配送状态

### 财务管理
- **起运国** — JOB成本支付/TTC管理/余额报表/利润统计/备用金/奖金管理/退赔/采购
- **到达国** — DPN成本支付/JOB成本支付/JOB到付余额/TTC管理/余额报表/利润统计/备用金/资金调拨/退赔/采购

### 审核管理
- 应收审核/成本审核（POL+POD）/DPN成本审核/备用金审核/退赔审核/采购审核

### 系统设置
- **价格体系** — 通用运价/类别运价配置（首重/续重/阶梯价）
- **国家管理** — 国家/城市/区/站点的增删改、站点捆绑
- **基础数据** — 供应商管理（个人/企业）、物流状态设置、财务/费用项目
- **权限管理** — 权限模板管理、账户管理
- **员工管理** — 员工信息/岗位职责/工资/考勤
- **用户中心** — 注册用户/收件人信息/用户捆绑绑定
- **汇率管理** — 到付订单币种换算

### 辅助功能
- **服务指南** — 界面管理（CMS内容管理）、国际汇率
- **加盟合作** — 加盟优势展示、加盟申请处理
- **工作报告** — 销售报告/拜访报告
- **推广管理** — 信息推广发布
- **采购管理** — 采购列表
