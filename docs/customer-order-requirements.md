# 客户订单模块需求分析

> 来源：客户提供的表单数据（订单列表2022.xlsx，8个Sheet）
> 分析日期：2026-03-07
> Excel Sheet 列表：列表、展列表开、订单详情、订单详情-展开、订单详情-展开-子状态、价格-日期、价格显示、创建订单

---

## 一、订单列表页

> 对应 Sheet：「列表」「展列表开」

### 多级筛选器（级联）
- 第1级：国家（全部 / 尼日利亚 / 加纳 / 几内亚 / 中国）
- 第2级：城市（如尼日利亚 → 拉各斯 / 卡诺 / 阿布贾 / 奥尼查）
- 第3级：站点（如拉各斯 → 伊科贾站点 / 电脑村站点 / 维岛站点 / 贸易展会站点）

### 筛选条件
- 日期范围（起始日期 ~ 结束日期）
- 服务类型（特快 / 普快）
- 支付方式（预付 / 到付）
- 支付状态（已付 / 未付）
- 用户
- 业务员

### 搜索框
支持多字段模糊搜索：订单号 / JOB号 / 集装号 / 快递单号 / 提单号 / 电话 / 收发货人名字

### 列表字段 — 收起视图（Sheet「列表」）
| 字段 | 说明 |
|------|------|
| 序号 | 自增序号 |
| 运单号 | 主运单号 |
| 用户 | 下单用户 |
| 业务员 | 负责业务员 |
| 线路 | 如 CAN.CHN→LOS.NGA |
| 服务类型 | 特快 / 普快 |
| 说明 | 普货 / 非普货 |
| 计费重量Kg | 计费重量 |
| 件数 | 货物件数 |
| 币种 | CNY / USD |
| 应收 | 应收金额 |
| 支付方式/状态 | 合并显示，如「到付 已付」「CC PAID」「CC UNPAID」 |
| 物流状态 | 如「已完成 IKEJ STA」「待入库 HAIZ STA」 |
| 更新日期 | 两行显示（创建日期 + 更新日期） |

### 列表字段 — 展开视图（Sheet「展列表开」）
与收起视图的区别：
- **支付方式、支付状态拆分为两列**（收起视图合并为一列）
- **币种列移除**
- **增加「订单日期」列**，与「更新日期」分开显示
- **主单可展开子单**：主单行下方缩进显示子单（如 2341234567890 → 001~009），子单行仅显示：运单号、说明、计费重量Kg、件数、订单日期、更新日期（其余字段继承主单）

### 操作
- 「创建订单」按钮

## 三、物流状态栏（可展开/收起）

> 三个层级的展示状态，对应不同 Sheet

### 层级1：状态栏收起（Sheet「订单详情」）
- 显示「展开状态栏」按钮
- 不显示任何子单物流信息

### 层级2：状态栏展开，子单收起（Sheet「订单详情-展开」）
- 显示「收起状态栏」按钮
- 每条子单一行，字段如下：

| 字段 | 示例 |
|------|------|
| JOB号 | JOB123456 |
| 订单号 | 190910000021 |
| 第三方运单 | 顺丰速运 SF1012605193752 |
| 路线+航司+提单号+集装号 | CAN-HKG-ADD-LOS  ET  071-12345678  AK2 |
| 状态 | 已完成 |
| 更新日期 | 2019/10/18 20:30:01 |
| 操作 | 展开 |

### 层级3：子单物流展开（Sheet「订单详情-展开-子状态」）
- 子单行增加集装号显示（如 `JOB123456  AK2  190910000021`）
- 展开后显示多站点物流节点时间线：

```
站点1（收货站）
  → 入库 / 集装 / 离库

白云区站点（广州总调度中心）
  → 入库 / 离库 / 到达机场 / 报关 / 查验 / 放行 / 离境

伊科贾站点（拉各斯总调度中心）
  → 到达机场 / 报关 / 查验 / 放行 / 入库 / 离库

甲毕站点（阿布贾调度中心）
  → 入库 / 离库

站点4（末端配送站）
  → 入库 / 通知 / 离库 / 已完成
```

- 每个节点显示具体时间戳（如 2019-10-24 15:10:56）
- 站点名称包含所属调度中心说明
- 不同子单可独立展开/收起

## 六、应收明细

> 三个 Sheet 中应收明细的列布局略有差异，体现不同的展示方案

### 方案A — 列拆分（Sheet「订单详情」）
| 字段 | 说明 |
|------|------|
| 序号 | 自增 |
| 项目 | 首重 / 续重 / 扣减运费 / 进口报关费 / 到门费用 / 折扣 |
| 单价USD | 单价 |
| 数量 | 数量（扣减运费数量为1，小计为负数） |
| 小计USD | 单价 * 数量 |
| 录入账号 | 操作人（如 SAMPAO） |
| 录入日期 | 时间（如 2019/10/18 20:30） |
| 支付方式 | 预付 / 到付（仅首行显示） |
| 支付状态 | 已付 / 未付（仅首行显示） |

### 方案B — 列合并（Sheet「订单详情-展开」）
| 字段 | 说明 |
|------|------|
| 序号 | 自增 |
| 项目 | 同上 |
| 单价USD | 单价 |
| 数量 | 数量 |
| 小计USD | 小计 |
| 录入账号 | 操作人 |
| 录入日期 | 时间 |
| 支付方式/状态 | 合并显示，如「预付 已付」（仅首行） |
| 支付途径 | 如「公账工（7228） 查看凭证 019/10/18 20:30:00」（仅首行） |

### 方案C — 紧凑合并（Sheet「订单详情-展开-子状态」）
| 字段 | 说明 |
|------|------|
| 序号 | 自增 |
| 项目 | 同上 |
| 单价USD | 单价 |
| 数量 | 数量 |
| 小计USD | 小计 |
| 录入账号/日期 | 合并为一列（如「SAMPAO 2019/10/18 20:30:00」） |
| 支付方式/状态 | 合并显示（仅首行） |
| 支付途径 | 含查看凭证链接+支付日期（仅首行，可显示多条支付记录） |

### 底部汇总（三个方案相同）
- 合计USD（如 405.6）
- 汇率（如 USD1.00=NGN535.00）
- 折合当地货币（如 NGN 41,786.40）

### 操作按钮
- 运价列表
- 导出账单

### 页面底部操作
- 返回
- 打印面单

## 七、运价列表

> 对应 Sheet：「价格-日期」「价格显示」

### 价格日期选择页（Sheet「价格-日期」）
- 左侧：历史价格日期列表（2019/1/19、2019/5/10、2019/3/11...）+ 「更多」展开
- 右侧：当前价格（如 2019年12月10日）
- 点击日期进入对应价格详情
- 注意：Excel 中日期以数字存储（如 43484 = 2019/1/19），需转换

### 价格详情页（Sheet「价格显示」）
- 路线标题：如 CAN.CHN-LOS.NGA
- 服务类型分区：普快（含时效说明）/ 特快
- 右上角显示更新日期 + 「历史价格」链接

### 价格表字段
| 项目 | 重量值KG | 预付(CNY) | 到付(USD) |
|------|----------|-----------|-----------|
| 首重 | 1KG | 70.00 | 10.20 |
| 续重 | >=1KG | 65.00 | 9.50 |
| 续重 | >=30KG | 55.00 | 8.00 |

### 附加规则
- 普货价格已含加纳进口清关费，需到仓自取
- 文件收费：预付 RMB100，到付 USD18，每份限0.5kgs以内
- 特殊商品加价：监控设备、内存卡、手机屏、假发 → 运价基础增加8.3%
- 超重规则：普货单体>42Kgs → 预付RMB78/KG，到付USD11.3/KG，时效10-12工作天
- 特快服务：不区分首续重，预付RMB83.00/KG，到付USD12.00/KG，时效2-4工作天
- 非普货默认特快服务（化妆品、食品、保健品、药品、少量粉末与液体）
- 计费规则：首重1KG，续重不足0.5KG按0.5KG，超0.5KG不足1KG按1KG
- 计费重量 = max(毛重, 体积重量)
- 禁运物品：液体、纯电池、粉末、军火武器、危险品、易燃易爆品等

## 八、创建订单

> 对应 Sheet：「创建订单」

### 发货人信息
| 字段 | 类型 |
|------|------|
| 名字 | 输入/选择 |
| 电话 | 输入 |
| 详细地址 | 输入 |
| 区 | 选择 |
| 城市 | 选择 |
| 国家 | 选择 |

### 收货人信息
同发货人，支持「添加地址」功能

### 货物明细（可多行动态添加）
| 字段 | 类型 |
|------|------|
| 物流公司 | 下拉选择（顺丰/韵达/圆通等） |
| 单号 | 输入 |
| 品名 | 输入 |
| 类别 | 下拉选择 |
| 说明 | 下拉选择（普货/非普货） |
| 重量Kg | 数字输入 |
| 件数Pcs | 数字输入 |
| 货值USD | 数字输入 |
| 备注 | 选择/输入 |

每行可删除（X 按钮），底部汇总总重量、总件数、总货值

### 操作按钮
- 返回
- 保存（暂存草稿）
- 提交（正式提交）
