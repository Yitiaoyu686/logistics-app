## 报表依赖关系

```
数据录入层
┌──────────────────────────────────────────────────────┐
│  OMS订单  TMS任务  WMS称重  费用录入  银行/支付导入    │
│  HR工资   固定资产台账  汇率配置  提成规则配置         │
└──────────────┬───────────────────────────────────────┘
               ↓
业务核算层
┌──────────────────────────────────────────────────────┐
│  R1 毛利表 ←──── 订单+费用+汇率                       │
│      ↓                                               │
│  R2 提成明细表 ←── R1 + 提成规则                      │
│  R3 应收统计表 ←── R1 + 回款数据                      │
│  R4 未付款清单 ←── R1 + 收款记录                      │
│  R5 利润总额表 ←── R1 + R2 + 经营费用                 │
│  R7 供应商对账 ←── R1(成本) + 银行支付                │
└──────────────┬───────────────────────────────────────┘
               ↓
汇总报表层
┌──────────────────────────────────────────────────────┐
│  R6  员工工资排行 ←── R2 + HR工资                     │
│  R8  收支流水汇总 ←── 银行/支付导入                   │
│  R9  固定资产折旧 ←── 资产台账                        │
│  R10 财务三表+分录 ←── R1~R9 全部汇总                 │
└──────────────────────────────────────────────────────┘
```

**核心链路**：R1(毛利) → R2(提成) + R3(应收) + R5(利润) → R10(财务三表)
**R1是一切的起点，R10是一切的终点。**
