### 1. 快递入库 Tab ⚠️ 多个关键缺失

#### Web 完整流程
1. **列表展示**（主单维度）
   - 字段：序号 / 主单号 / 客户 / 线路 / 业务员 / 三方运单数 / 收货进度（已入库 N/N）
   - 统计：今日入库 N / 今日件数 / 今日重量 / 异常待处理 / 无订单快递待匹配
   - 筛选：搜索（运单/三方运单/客户/线路）+ 待处理/支付方式/支付状态/业务员

2. **+ 展开主单** → 显示子运单（包裹）列表
   - 字段：三方运单号 / 快递公司 / 三方状态（已签收）/ 品名 / 件数 / 重量 / 长×宽×高 / 体积重 / 子运单号 / 入库状态 / 操作

3. **三方快递入库 Drawer**（点击「完成入库」或子运单的"入库"按钮 → InboundDetailDrawer）
   - **顶部**：运单号、客户、路线、运输方式、业务员、到货时间、签收状态
   - **入库录入区**：货物类别（下拉）+ 品名 + 重量 + 长 + 宽 + 高 + 件数 + 备注
   - **入库照片**：多张图片上传 + 删除
   - **费用明细** ⭐ **关键缺失**
     - 第一行**自动计算运费**（蓝色 Tag「自动」）：
       - 计费重 = max(实重, 体积重)
       - 海运 12 USD/kg，空运 55 USD/kg；海运起步 50，空运起步 150
       - 备注自动写入：实重 X kg | 体积重 X kg | 计费重 X kg
     - 「**+ 添加费用**」按钮 — 手动添加：
       - 费用类型（操作费/关税/仓储/派送/报关/加固/上门取件/到门费用…）
       - 币种（USD/CNY/NGN…）
       - 单价 + 数量 + 汇率 + 金额（自动算）+ 备注
       - 删除按钮
     - 合计 USD（汇总所有费用）
   - 操作按钮：返回 / 保存

4. **添加三方快递 Modal**（点「添加三方运单」）
   - 三方运单号（必填）
   - 快递公司下拉（顺丰/圆通/中通/韵达/申通/京东/德邦…）
   - 品名

5. **打印面单 Modal**（点子运单"打印面单"）
   - 显示运单号、客户、目的地、品名、件数、重量
   - 打印预览（demo 是预览图）

6. **完成入库 Modal.confirm**（点主单"完成入库"）
   - 标记主单关闭，后续不能再加三方快递
