## 二、综合协同域

### 2.1 工作台（Dashboard）

#### Tab 1: 角色待办

- **统计卡片**: 账号总数(10)、角色管理入口(1)、权限配置入口(1)、流程管理入口(1)
- **系统支撑区**: 用户账号管理(待处理数)、角色管理(待处理数)、审批流程维护(待处理数)
- **系统处理进展**: 按用户显示最近操作（账号已创建、更新时间等）
- **角色切换选择器**: 下拉选择不同角色工作台

#### Tab 2: 待办事项

- **表格字段**: 标题、优先级、状态、截止日期、关联单号、创建时间、操作
- **操作**: + 新建待办

#### Tab 3: 预警中心

- **统计**: 待处理数、高优先级数、处理中数
- **子Tab**: 待处理 | 处理中 | 已解决 | 已忽略 | 全部
- **表格字段**: 预警编号、预警类型、严重程度、标题、关联单号、操作

#### Tab 4: 全流程联调（V2）

- **参数**: 业务线(海运SEA/空运AIR)、起运仓ID、到达仓ID、联调应收金额(CNY)
- **9步流程**:
  1. 创建客户
  2. 创建主订单
  3. 创建任务预置
  4. 主单入库并生成子单
  5. 绑定子单到任务
  6. 推进运输节点
  7. 创建DPN并签收
  8. 费用提报审核收款
  9. 回读最终状态
- **产物追踪**: 客户ID、主单ID、子单ID、子单数量、任务ID、DPN ID、配送任务ID、费用单ID
- **最终状态**: 主单状态、子单状态

## 五、核心业务流程（全流程联调 V2）

```
客户 → 主订单 → 主单入库自动生成子单(每包裹=1子单) → 任务绑定 → DPN签收 → 费用审批收款
```

### 详细9步流程


| 步骤 | 环节       | 操作               | 产物                        |
| ---- | ---------- | ------------------ | --------------------------- |
| 1    | CRM        | 创建客户           | 客户ID (CUST-xxx)           |
| 2    | OMS        | 创建主订单         | 主单号 (S-/A-xxxxxxx)       |
| 3    | TMS        | 创建任务预置       | 任务号 (S-JOB/A-JOBxxxxxxx) |
| 4    | WMS-Origin | 主单入库并生成子单 | 子单号 (主单号-01/-02...)   |
| 5    | WMS-Origin | 绑定子单到任务     | 子单↔任务关联              |
| 6    | TMS        | 推进运输节点       | 节点状态更新                |
| 7    | WMS-Dest   | 创建DPN并签收      | DPN号、配送任务ID           |
| 8    | Finance    | 费用提报审核收款   | 费用单号 (FEE-xxx)          |
| 9    | -          | 回读最终状态       | 主单/子单最终状态           |

### 关键实体编号规则


| 实体      | 海运前缀 | 空运前缀 | 格式示例            |
| --------- | -------- | -------- | ------------------- |
| 主订单    | S-       | A-       | S-20260320990001    |
| 子单      | S-       | A-       | S-20260320990001-01 |
| 任务(JOB) | S-JOB    | A-JOB    | S-JOB26030001       |
| 费用单    | FEE-     | FEE-     | FEE-20260320-702    |
| 客户      | CUST-    | CUST-    | CUST-177397xxx      |
| DPN       | DPN-     | DPN-     | DPN-20260320-1561   |

## 六、数据实体关系

```
Client (客户)
  └── MasterOrder (主订单) [1:N]
        └── SubOrder (子单/包裹) [1:N，入库时自动生成]
              └── ShippingUnit (集装箱/航空单元) [N:1，装箱绑定]
                    └── Job (运输任务) [N:1]
                          ├── TransportNode (运输节点) [1:N]
                          ├── DPN (配送/自提通知) [1:N]
                          │     └── DeliveryTask (配送任务) [1:1]
                          └── Fee (费用单) [1:N]
                                └── ApprovalFlow (审批流) [1:1]
```
