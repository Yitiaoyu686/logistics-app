## 海运拼箱计费规则20260226.docx

海运拼箱（LCL）计费规则
一、核心换算标准
海运拼箱的计费采用体积与重量换算对比的方式，换算标准为：
1立方米 = 700公斤
二、计费逻辑
1. 先判断货物是“轻货”还是“重货”
计算货物的实际密度：
密度=实际毛重（公斤）/实际体积（立方米） 
如果密度 ≤ 700，说明货物为轻货；
如果密度 > 700，说明货物为重货。
2. 根据货物类型确定计费基础
轻货：按货物的实际体积计费。
重货：按货物的毛重换算成体积计费，换算公式为：换算体积=实际毛重（公斤）/700​
3. 最终计费体积
比较两个数值，取较大者作为最终计费体积：
三、示例说明
示例1：轻货
实际体积：2立方米
实际毛重：1000公斤
密度：1000 ÷ 2 = 500 ≤ 700 → 轻货
换算体积：1000 ÷ 700 ≈ 1.43立方米
比较：实际体积2立方米 > 换算体积1.43立方米
最终计费体积：2立方米
示例2：重货
实际体积：2立方米
实际毛重：1800公斤
密度：1800 ÷ 2 = 900 > 700 → 重货
换算体积：1800 ÷ 700 ≈ 2.57立方米
比较：换算体积2.57立方米 > 实际体积2立方米
最终计费体积：2.57立方米
四、规则总结
货物类型	判断标准	计费依据
轻货	毛重÷体积 ≤ 700	按实际体积计费
重货	毛重÷体积 > 700	按毛重÷700换算体积计费
最终计费	-	取实际体积与换算体积的较大值
不规则包装	-	按最长、最宽、最高点测量计算

## 空运计费规则20260226.docx

空运计费规则（中文描述）
一、计费重量确定规则
实际毛重：货物在磅秤上称出的实际重量，单位为公斤（KG）。
体积重量：根据货物外箱尺寸计算，计算公式为：
体积重量=长(cm)×宽(cm)×高(cm)/6000 
计费重量：比较实际毛重和体积重量，取两者中较大值作为计费重量。
二、重量进位规则
首重：第1公斤按整公斤计。
续重：
不足0.5公斤按0.5公斤计；
超过0.5公斤不足1公斤按1公斤计。
三、运费计算规则（核心）
运费采用首重 + 续重的分段计算方式：
1. 首重部分
第1公斤单独计费，适用首重价格。
无论货物总重多少，第1公斤固定按首重价格收取。
2. 续重部分
总重量减去第1公斤后，剩下的重量称为续重。
续重部分根据其总重量落入哪个阶梯区间，确定该续重部分的统一单价。
续重部分整体按该单价计算，不再分段。
3. 价格阶梯表（人民币预付价）
重量区间	   单价（元/公斤）	说明
首重 1公斤	    63.00	仅限第1公斤
续重 ≥1公斤	60.00	续重部分在1~5公斤之间适用
续重 ≥5公斤	57.00	续重部分在5~20公斤之间适用
续重 ≥20公斤	55.00	续重部分超过20公斤适用
4. 计算示例（15公斤普货）
货物总重：15公斤
首重部分：1公斤 × 63元 = 63元
续重部分：14公斤（15-1）
续重部分落在“≥5公斤”区间 → 单价57元/公斤
续重费用：14公斤 × 57元 = 798元
总运费：63元 + 798元 = 861元
四、附加费规则
1. 非普货附加费（在基础运费上按百分比加收）
带电产品、带磁产品、食品、化妆品	+10%	基础非普货附加费
化工品（非危险品）+25%	
药品、保健品+40%	
手机+60%	
2. 包装附加费
木箱包装：在基础运费上加收 2元/公斤（按计费重量计算）。
3. 混装计费规则
普货与非普货混装：整票按非普货价格计费；
多种非普货混装：按附加费率最高的那种货物计费。
五、其他重要规则
费用包含：报价为普货双清价，已包含尼日利亚进口税费，但需收货人到仓库自取。
文件寄送：预付150元/份，到付21美元/份，限0.5公斤以内。

## 尼日利亚奖金制度初稿 海运.docx

本制度适用于国际海运拼箱业务，自2024年11月1日起执行，适用于尼日利亚地区正式员工（试用期后）。
客户归属与行为规范
为确保销售业绩的公平计算，并防止内部不正当的客户争夺行为，销售人员需严格遵守以下规定：
1. 客户归属：已归属销售人员的客户，包括委托人和收货人，均视为该销售员的客户资源。其他销售人员不得以任何理由将其归为自己的客户。
2. 禁止争夺客户：
2.1在办公室或仓库向已归属其他销售人员的客户推销自己或争取客户资源。
2.2联合其他部门同事以不正当手段获取其他销售人员的客户信息。
3.如发现任何销售人员通过不当手段争夺已有客户或参与其他不正当抢客行为，公司将采取以下惩罚措施：
3.1取消该客户相关订单的业绩归属。
3.2撤销该销售人员在该客户上的所有奖金。
3.2严重违规者将面临扣除当月奖金的处罚，影响晋升或可能辞退。
奖金与业绩计算
1. 销售业绩以当月JOB项下产生的货物体积为基础。
2. 销售人员账户下的订单及其相关联客户的订单均计入该销售人员的业绩。
3. 应收款回收：当月所有订单的应收款需全部回收后，方可计算销售业绩。货物上月的奖金在当月25日发放，如上月订单未完成或应收款未收回，则延至下月25日发放。
4. 业绩前提条件：订单应收款回收是计算业绩与奖金的前提条件。若发生拒收、拒付或坏账导致公司损失，将从奖金中扣除，若当月奖金不足以抵扣，则从后续月份的奖金中扣除。
5. 基本任务量：以货物体积为计算标准，每月基本任务量为50立方米，不计算奖金，超出部分方计提奖金。
奖金方案
基本任务量：以货物体积为计算标准，每月基本任务量为30立方米，不计算奖金，超出部分方计提奖金。
方案A
例子：当月实际完成 90立方米，超出任务部分为90-30=60立方米，按每立方米NGN5,000计算如下：
奖金 = 60立方× NGN5,000 = NGN300,000.00
总奖金 = NGN300,000.00
方案B
例子：当月实际完成 190立方米，超出任务部分为190-30=160立方米，奖金按两个区间分别计算如下：
区间一：30到100立方米之间的部分为 100−30=70立方米，按每立方米NGN5,000计算：
奖金 = 70立方米 × NGN5,000 = NGN350,000.00
区间二：100到190立方米之间的部分为 190−100=90立方米，按每立方米NGN9,000计算：
奖金 = 90立方米 × NGN9,000 = NGN810,000.00
总奖金 = NGN350,000.00 + NGN810,000.00 = NGN1,160,000.00
方案C
例子：当月实际完成 500立方米，超出任务部分为500-30=470立方米，奖金按三个区间分别计算如下：
区间一：30到100立方米之间的部分为 100−30=70立方米，按每立方米NGN5,000计算：
奖金 = 70立方米 × NGN5,000 = NGN350,000.00
区间二：100到200立方米之间的部分为 200−100=100立方米，按每立方米NGN9,000计算：
奖金 = 100立方米 × NGN9,000 = NGN900,000.00
区间三：200立方以上的部分为 500−200=300立方米，按每立方米NGN15,000计算：
奖金 = 300立方米 × NGN15,000 = NGN4,500,000.00
总奖金 = NGN350,000.00 + NGN900,000.00 + NGN4,500,000.00 = NGN5,750,000.00
薪酬与绩效考核
聘请销售人员需大学本半毕业或三年以上同行业销售经验
基本薪资：试用期月薪为NGN90,000，转正后月薪为NGN110,000。
2. 试用期转正：试用期为3个月，试用期内完成货量1,000kg方可转正。
3. 绩效奖励：连续3个月达到方案B要求，从第4个月起绩效工资增加NGN20,000；连续3个月达到方案C要求，从第4个月起绩效工资增加NGN50,000。
4. 绩效扣减：连续3个月未达到方案A要求，从第4个月起绩效工资扣减NGN20,000。
5. 淘汰机制：连续5个月未达到基本任务要求，予以辞退。
6. 其他考核：有以下行为可酌情减薪或辞退：
6.1不主动执行工作任务
6.2工作消极
6.3不利于团队合作
6.4造成公司经济损失或负面影响
6.5不尊重同事或客户
