### 报表1B：毛利表（非LOS目的地 空运）- NBO/JNB/加纳/越南

**维度**：按月 × 按目的地
**粒度**：每条运单
**总列数**：24-25列（比LOS少6-7列）

**与LOS毛利表的关键差异**：

| 差异点 | LOS毛利表 | 非LOS毛利表 |
|--------|-----------|-------------|
| 应收部分 | 7列（应收RMB + NGN + USD + 汇率 + 到付USD + 汇率 + 人民币） | **4列**（应收RMB + 应收USD + 汇率 + 人民币） |
| 业务员列 | 有 | NBO无，JNB/加纳/越南有 |
| 目的港收款 | 分奈拉(NGN)和美元(USD)两路 | 仅有"应收USD"一个字段 |
| 总列数 | 31 | 24-25 |

**非LOS应收字段**：

| # | 字段名 | 说明 |
|---|--------|------|
| 8/9 | 应收RMB | 国内人民币应收 |
| 9/10 | 应收USD | 应收美元 |
| 10/11 | 汇率 | USD折算汇率 |
| 11/12 | 人民币 | USD折算RMB |

起运港成本和目的港成本结构与LOS相同。

### 报表4：提成明细表（海运-68立方）

**维度**：按月 × 按业务员
**粒度**：每条运单

#### 4A. 业务员明细Sheet
字段与毛利表（海运）完全一致，32列。
**业务员**：黄颖、三凤、朱小飞、吕沛霖、罗伟健、苏慧琪、罗珮文、陆总、浦生、无人（按月份有所变化）

#### 4B. 提成总表Sheet

| # | 字段名 | 说明 | 数据来源 |
|---|--------|------|----------|
| 1 | 姓名 | 业务员姓名 | 系统用户 |
| 2 | LOS毛利 | 该业务员LOS目的地毛利总额 | **计算字段** |
| 3 | 计费体积(立方) | 该业务员总计费体积 | **计算字段** |
| **6千-3.5万阶梯** | | | |
| 4 | 基数 | 保底基数（如6000或3000） | 提成规则配置 |
| 5 | 提成计数 | = 毛利 - 基数 | **计算字段** |
| 6 | 提成点数 | 提成比例（40%/15%/10%，因人而异） | 提成规则配置 |
| 7 | 提成金额 | = 提成计数 × 提成点数 | **计算字段** |
| **3.5万以上阶梯** | | | |
| 8 | 基数 | 高阶保底基数（35000） | 提成规则配置 |
| 9 | 提成计数 | = 毛利 - 高阶基数 | **计算字段** |
| 10 | 提成点数 | 高阶提成比例（50%） | 提成规则配置 |
| 11 | 提成金额 | = 提成计数 × 提成点数 | **计算字段** |
| 12 | **合计提成金额** | 各阶梯提成之和 | **计算字段** |
| 13 | 备注 | 特殊说明（如"小飞6-7月份原方案10%"） | 手工填写 |

**提成规则说明**：
- 基本任务：毛利不足6千的不计提成（下月基数补足）
- 6千-3.5万：黄颖/吕沛霖/浦生/陆总按40%，三凤/朱小飞按10%-15%
- 3.5万以上：按50%提成
- 陆总特殊处理：无基数要求，直接按40%

#### 4C. 发放Sheet
结构同提成总表，含"领款人"签名位置，用于实际发放确认。

### 2.2 数据获取方式

```
┌─────────────────────────────────────────────────────────┐
│                  系统自动计算的报表                        │
│                                                         │
│  订单数据(OMS) ──→ 毛利表(报表1,2)                       │
│       ↓              ↓                                  │
│  费用录入 ──→ 应收统计(报表5,6) ──→ 未付款清单(报表10)     │
│       ↓              ↓                                  │
│  毛利汇总 ──→ 提成计算(报表3,4) ──→ 员工排行(报表12)       │
│       ↓              ↓                                  │
│  利润分成(报表7) ──→ 利润总额(报表8)                       │
│                                                         │
├─────────────────────────────────────────────────────────┤
│                  外部导入的数据                            │
```
