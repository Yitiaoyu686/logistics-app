## 一、整体架构

### 1.1 布局框架：RuoYi-Vue 风格

采用经典后台管理系统布局：
- **左侧**：可折叠侧边栏菜单（深色主题）
- **顶部**：面包屑导航 + 用户信息 + 角色切换
- **内容区**：Tab 页签导航 + 搜索/筛选区 + 操作工具栏 + 数据表格 + 分页

技术实现：保持现有 `MENU_CONFIG` + `ContentRenderer` 状态驱动架构，调整布局样式。

### 1.2 空运/海运业务拆分策略

**方案：页面级 `Segmented` 切换器**

- 在需要区分空运/海运的页面顶部，放置 `空运 | 海运` 切换控件
- 切换后，页面内的数据列表、筛选条件、表单字段、计费规则等全部联动更新
- 财务中心和经营分析模块使用三态切换：`全部 | 空运 | 海运`
- 客户中心、系统设置等通用模块不需要切换器

**优势**：
- 菜单结构简洁，不重复
- 用户可快速对比两种业务
- 未来扩展陆运等业务类型只需加一个选项

## 二、订单管理

### 2.1 订单列表

- 页面顶部：`Segmented` 切换 `空运 | 海运`
- 筛选区：多级级联筛选（国家→城市→站点）、日期范围、服务类型、支付方式/状态、用户、业务员
- 搜索框：订单号/JOB号/集装号/快递单号/提单号/电话/收发货人
- 列表：收起/展开两种视图，主单可展开子单
- 操作：创建订单按钮

### 2.2 创建订单

- 空运和海运分别在各自模式下新建
- 共同字段：发货人、收货人、货物明细（物流公司/单号/品名/类别/说明/件数/备注）
- **空运特有**：重量Kg、货值USD、服务类型（普快/特快）
- **海运特有**：体积CBM、重量Kg（用于换算）、入仓号自动生成、拼柜/整柜选项
- 支持批量录入快递单号（智能粘贴识别）
- 备注：固定选项 + 自定义内容

### 2.3 订单详情

采用 **Anchor 锚点导航**：左侧固定锚点菜单，右侧滚动内容区。

锚点分区：
1. **基本信息** — 运单号、服务类型、业务员、日期/支付信息、用户/公司信息、发票信息
2. **路线与收发货人** — 发货人/收货人详细信息
3. **物流状态** — 可展开/收起的多级物流节点时间线（站点→子状态）
4. **订单初始信息** — 用户下单时填写的货物明细
5. **订单实际信息** — 仓库实际操作后的货物数据
6. **应收明细** — 费用项目列表 + 汇总 + 汇率换算

### 2.4 计费差异

| 维度 | 空运 | 海运 |
|------|------|------|
| 计费单位 | KG（千克） | CBM（立方米） |
| 计费重量 | max(毛重, 长×宽×高/6000) | max(实际体积, 毛重/700) |
| 价格结构 | 首重+续重阶梯价 | 按CBM单价 |
| 附加费 | 非普货+10%~60% | — |
| 超重规则 | 单体>42Kg特殊价 | — |

### 2.5 实际信息表格差异

**空运**：第三方运单、订单号、集装号、状态、品名、说明、尺寸cm、件数、体积重Kg、毛重Kg
**海运**：第三方运单、订单号、集装号、状态、品名、说明、尺寸cm、件数、体积CBM、毛重Kg

## 三、仓储管理

### 3.1 起运国仓储

页面顶部 `Segmented` 切换 `空运 | 海运`。

- **货物入库**：扫描入库，录入重量/尺寸，自动识别更新物流状态
- **库存列表**：以子订单维度展示，操作包括取消/退运，显示未完成入库订单
- **运输单元管理**：
  - 空运：集装打包（关联集装号，扫码装箱）
  - 海运：集装箱管理（提前生成集装箱号）
- **调拨管理**：创建调拨单，A点→B点

### 3.2 到达国仓储

- **货物入库**：目的国到仓入库
- **DPN入库**：DPN维度的入库管理
- **库存列表**：目的国仓库库存
- **配送管理**：执行DPN任务、配送列表、跟踪配送状态

## 四、办公/调度管理

### 4.1 起运国办

- **任务管理**：创建运输任务（选择运输方式/承运人）、执行任务
- **出口跟踪**：物流状态跟踪（到达口岸→出口申报→海关查验→放行→离境）
- **JOB成本录入**：JOB维度的成本录入
- **应收管理**：变更/确认支付/审核
- **订单费用**：订单维度费用录入

### 4.2 到达国办

- **任务管理**：创建DPN/配送单
- **进口跟踪**：到达机场→进口申报→海关查验→放行→入库
- **通知客户**：货物到达后通知取件/配送
- **JOB成本录入POD**：目的国JOB成本
- **DPN成本**：配送单成本管理
- **应收管理**：目的国维度应收

## 八、技术要点

| 项目 | 方案 |
|------|------|
| 框架 | React 19 + TypeScript + Vite 7 + Ant Design v6 |
| 布局 | RuoYi-Vue 风格（左侧菜单 + 顶部面包屑 + Tab页签） |
| 导航 | 保持 `MENU_CONFIG` + `ContentRenderer` 状态驱动 |
| 业务切换 | 页面级 `Segmented` 组件，状态提升到页面层 |
| 样式 | 内联样式 + `theme.useToken()` |
| 状态管理 | `useState` + `useMemo` |
| 数据 | Mock 数据，本地状态切换 |
| 订单详情 | Ant Design `Anchor` 组件实现锚点导航 |
| 日期 | Day.js |
