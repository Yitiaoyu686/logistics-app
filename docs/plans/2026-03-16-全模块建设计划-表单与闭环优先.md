## 2. 建设总原则

1. 海运与空运完全隔离，页面、任务、费用、节点全部按业务线分开。
2. 先做业务闭环，再做报表与内容运营。
3. 先做“表单 + 详情页 + 审核流”，确保数据可追踪。
4. 所有状态变化必须落日志，支持责任追溯。
5. 编号系统自动生成，客户编号短码保留。

## 3. 闭环目标（第一优先级）

必须先打通这条链路：

1. 客户主档 -> 创建主订单（可无实货）
2. 仓库收货入库 -> 每个包裹生成一个子订单
3. 集装号管理 -> 子订单绑定集装号
4. 办公室建任务 -> 集装号绑定任务并推进节点
5. 到达仓/DPN/配送 -> 全部包裹签收
6. 费用提报 -> 销售沟通 -> 财务审核
7. 子订单异常 -> 办公室/财务审核 -> 闭环

## 4. 分阶段建设计划

### 阶段A（P0）基础数据与权限底座

目标：保证所有业务表单有可选项来源，不再硬编码。

建设内容：

1. 基础设置：国家/城市、站点、仓库、供应商、服务类型、费用项、汇率、路线模板。
2. 组织权限：站点、部门、用户、角色、权限矩阵（站点+业务线+模块）。
3. 节点模板：内置海运/空运常规模板，管理员可在任务中增删改。

关键表单/详情页：

1. 基础数据维护表单（增删改查）
2. 用户与角色授权表单
3. 路线模板详情页（含节点定义）

验收标准：

1. 所有业务表单的下拉选项都来自数据库。
2. 同一账号只能看到授权站点与业务线数据。

### 阶段B（P1）客户中心（公共模块）

目标：客户数据成为海运/空运共享主档，支持后续订单录入。

建设内容：

1. 我的客户/公海池列表统一字段。
2. 客户认领、转移跟进、释放、公海日志。
3. 发货人/收货人多条资料维护（分开增删改）。

关键表单/详情页：

1. 快速创建客户表单
2. 客户详情页（基础档案/业务档案/收发货信息/订单）
3. 公海流转记录详情

验收标准：

1. 客户编号唯一短码，海空共用。
2. 客户池流转日志完整可回溯。

### 阶段C（P2）OMS主链（订单表单与详情页核心）

目标：完成“主订单创建 + 订单详情可追踪 + 子订单可查看”。

建设内容：

1. 主订单创建表单：客户、线路、服务类型、收发货、快递包裹初始信息。
2. 订单列表：支持文档要求的筛选与搜索（订单/JOB/集装号/快递号/提单号/电话等）。
3. 订单详情：
   - 主单汇总信息
   - 子订单列表
   - 包裹初始信息与实际信息
   - 节点状态栏
   - 费用与异常区块

关键表单/详情页：

1. 新建订单表单
2. 订单列表（海运/空运独立）
3. 订单详情页（按文档结构重构）

验收标准：

1. 主订单可先创建且无实货。
2. 订单详情可看到主单、子单、包裹、状态日志。

### 阶段D（P3）起运国仓（入库与待匹配池）

目标：实现“每包裹一子订单”与无订单快递处理。

建设内容：

1. 入库表单：录入尺寸/重量/件数/状态。
2. 入库规则：每次收货一个包裹，自动生成一个子订单。
3. 无订单待匹配池：
   - 入池
   - 推荐匹配
   - 手工挂单
4. 库存列表与状态流转。

关键表单/详情页：

1. 入库登记表单
2. 无订单待匹配列表与匹配表单
3. 库存列表与库存详情

验收标准：

1. 入库后自动新增子订单且与包裹一一对应。
2. 无订单快递可完成“入池 -> 推荐 -> 匹配 -> 入单”闭环。

### 阶段E（P4）起运国办（任务与集装）

目标：建立任务驱动的执行主线。

建设内容：

1. 办公室创建任务（海运订舱/空运订板位）。
2. 任务绑定多个集装号。
3. 子订单绑定集装号（支持跨集装号）。
4. 发运/报关/清关节点推进。

关键表单/详情页：

1. 任务创建表单
2. 任务详情页（集装号、子订单、节点时间轴）
3. 出口跟踪列表与详情

验收标准：

1. 一个任务可管理多个集装号。
2. 节点推进有角色边界（仓库首尾、办公室中段）。

### 阶段F（P5）到达国办/仓（DPN与签收）

目标：完成到达侧配送闭环。

建设内容：

1. 创建DPN（关联子订单）。
2. DPN入库、配送派单、签收回传。
3. 全部包裹签收后，主订单自动完成。

关键表单/详情页：

1. DPN创建表单
2. 配送任务表单与签收表单
3. DPN详情与配送轨迹

验收标准：

1. DPN全程可追踪到子订单。
2. 签收规则按“全部包裹完成”生效。

### 阶段G（P6）费用、审核与财务

目标：实现跨环节费用闭环与审核闭环。

建设内容：

1. 费用提报（订单/子订单/JOB/DPN层级）。
2. 销售沟通记录。
3. 财务审核与驳回重提。
4. 异常审核（办公室+财务）。

关键表单/详情页：

1. 费用提报表单
2. 费用审核列表与详情
3. 异常登记与审核详情

验收标准：

1. 费用变更必须经过财务审核。
2. 异常处理有状态、有审核、有结果。

### 阶段H（P7）辅助与运营模块

目标：补齐非主链但客户要求的运营能力。

建设内容：

1. 服务指南、推广管理、加盟合作。
2. 工作报告、采购管理。
3. 员工管理与用户中心深度联动。

关键表单/详情页：

1. CMS配置表单与发布详情
2. 报告提交流程表单
3. 采购与审批表单
