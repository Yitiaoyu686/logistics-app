# 2026-03-16 订单详情 Full 字段来源与联调说明（V2）

## 2. 字段来源与业务含义

| Full字段 | 数据来源表 | 写入角色/环节 | 说明 |
|---|---|---|---|
| `order` | `oms_order` | 销售/客服创建订单，财务更新支付快照 | 主单快照（业务线、支付、收发货、路线） |
| `subOrders` | `oms_sub_order` | 仓库收货创建子单，任务绑定后更新任务字段 | 子单维度实际执行体 |
| `initialPackages` | `oms_order_package_initial` | 下单阶段录入/导入 | 客户预报包裹 |
| `actualPackages` | `oms_order_package_actual` | 仓库入库实操 | 实际称重、体积、状态 |
| `statusLogs` | `oms_order_status_log` | 订单状态变化自动写入 | 订单/子单状态日志 |
| `trackingEvents` | `tms_tracking_event` | 仓库/办公室/配送更新节点 | 全量事件原子明细 |
| `trackingBySubOrder` | `tms_tracking_event` 聚合 | 后端按子单+站点+节点聚合 | 详情页“物流状态栏”直接消费 |
| `jobBindings` | `tms_job_order_rel` + `tms_job` + `tms_shipping_unit` | 办公室绑定任务/集装 | 子单与任务、集装关系 |
| `routeTemplate` | `routes_config` + `route_logistics_nodes`（系统基础设置） | 管理员配置路线模板 | 计划路径节点，供“计划 vs 实际”对照 |
| `dpns` | `pod_dpn` | 到达国仓/办公室创建派送单 | 终端配送主单 |
| `dpnItems` | `pod_dpn_item` | 派送配货 | DPN 与子单关联 |
| `deliveryTasks` | `pod_delivery_task` | 配送员接单/签收 | 终端任务执行状态 |
| `fees` | `fin_fee` | 仓库/办公室提费用，财务审核 | 应收/应付费用 |
| `payments` | `fin_payment` | 财务确认收付 | 付款流水 |

## 3. 站点与节点来源结论（当前实现）

- 详情页站点节点优先来自 `trackingBySubOrder`（事件事实数据）。
- 每个节点时间来自 `tms_tracking_event.event_time`，不是前端模板时间。
- 站点名优先级：`extra_json.siteName` > `location` > `未分配站点`。

## 4. 当前已形成的数据闭环（订单详情视角）

1. 创建订单：`oms_order` + `oms_order_package_initial`
2. 仓库入库：`wms_inbound_order`/`wms_inbound_item` + `oms_order_package_actual`
3. 任务绑定：`tms_job` + `tms_shipping_unit` + `tms_job_order_rel`
4. 物流推进：`tms_tracking_event` -> 聚合到 `trackingBySubOrder`
5. 终端配送：`pod_dpn` + `pod_dpn_item` + `pod_delivery_task`
6. 财务核对：`fin_fee` + `fin_payment`

## 5. 前端详情页对应变化

- 子单展开区不再依赖固定站点模板；改为显示后端返回的真实站点节点。
- 展示样式改为紧凑条带，减少空白占位。
- 子单下可直接看到 DPN 与配送任务状态标签。
