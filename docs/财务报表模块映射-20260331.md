## 详细映射

### R1 毛利表 → 财务中心 > 财务报表

**现有页面**：
- `fin_cost_report` → CostReport（成本报表）—— 按订单/JOB的成本明细
- `fin_job_profit` → JobProfitDashboard（JOB利润看板）—— 利润可视化
- `fin_job_audit` → JobCostAudit（JOB成本审核）—— 成本审核明细

**映射方案**：

| 毛利表内容 | 放在哪 | 说明 |
|-----------|--------|------|
| 运单级明细（32列） | **CostReport** 改造 | 增加"毛利表"Tab，按月/目的地/空运海运筛选，展示完整的应收-成本-利润明细 |
| JOB级利润汇总 | **JobProfitDashboard** 改造 | 增加按JOB汇总利润的表格视图（对应海运毛利表的"总表"Sheet） |
| 成本审核钻取 | **JobCostAudit** 保持 | 点击单条JOB可查看所有运单的成本构成 |

**筛选维度需支持**：
- 运输方式：空运 / 海运（已有 BusinessModeSwitcher）
- 目的地：LOS / NBO / JNB / ACC / 越南 等
- 月份：月度筛选
- 业务员：按归属业务员筛选

**数据来源页面**（录入端）：
- 起运港成本 ← `tms_cost_pol_list`（JobCostInputPOL）已有
- 目的港成本 ← `tms_cost_pod_list`（JobCostInputPOD）已有
- 订单费用 ← `tms_order_fee_list`（OrderFeeInput）已有
- 汇率 ← `set_base_exchange`（ExchangeRateManagement）已有

### R2 提成明细表 → 财务中心 > 提成与薪资

**现有页面**：
- `fin_commission` → CommissionCalculation（提成计算）
- `fin_commission_rules` → CommissionRuleManagement（提成规则）

**映射方案**：

| 提成表内容 | 放在哪 | 说明 |
|-----------|--------|------|
| 业务员明细Sheet | **CommissionCalculation** 改造 | 选择业务员后，展示该员工当月所有运单的毛利明细（数据直接引用R1） |
| 提成总表（空运） | **CommissionCalculation** 改造 | 增加"空运提成汇总"Tab，按目的地分列票数/毛利，底部合计+基数+提成计数 |
| 提成总表（海运-68） | **CommissionCalculation** 改造 | 增加"海运提成汇总"Tab，展示阶梯计算（6千-3.5万/3.5万以上） |
| 发放确认单 | **CommissionCalculation** 改造 | 增加"生成发放单"功能，导出含领款人签名栏的PDF |
| 提成规则配置 | **CommissionRuleManagement** 保持 | 配置基数、提成比例、阶梯规则、个人差异化比例 |

**需增加的规则配置字段**：
- 空运：保底票数、保底毛利金额
- 海运：基数（6000/3000因人而异）、阶梯分界（35000）、各阶梯比例（40%/15%/10%/50%）
- 个人特殊规则（如"陆总无基数"、"三凤/朱小飞按10%"）

### R10 财务三表+分录 → 财务中心 > 财务报表 🆕

**现有页面**：无

**新增方案**：

在财务中心 > 财务报表子模块下新增2个页面：

#### 页面1：财务报表

```
菜单项：fin_financial_statements → FinancialStatements（财务报表）
路径：client/src/pages/finance/FinancialStatements.tsx
角色：FINANCE, ADMIN, BOSS
```

**4个Tab**：

| Tab | 内容 | 数据来源 |
|-----|------|----------|
| 利润表 | 标准利润表（收入/成本/毛利/营业费用/财务费用/营业利润/营业外收支/利润总额/净利润） | R1+R5+R8 汇总 |
| 资产负债表 | 资产类（现金/银行/应收/存货/固定资产）+ 负债权益类（应付/借款/实收资本/利润） | R3+R7+R8+R9 汇总 |
| 科目汇总表 | 各科目期初/本期发生/期末余额 | 分录自动汇总 |
| 会计分录 | 凭证号/摘要/会计科目/明细科目/借/贷 + 损益类科目发生额汇总 | 系统自动生成+手工调整 |

#### 页面2：资金明细表

```
菜单项：fin_fund_detail → FundDetail（资金明细表）
路径：client/src/pages/finance/FundDetail.tsx
角色：FINANCE, ADMIN, BOSS
```

**内容**：按月展示各资金渠道的摘要+金额明细（对应原Excel"X月份明细"Sheet），每个渠道一列对。

**注**：此页面与R8（CashFlowDaily）数据相同但展示方式不同 —— R8是按渠道筛选的流水视图，FundDetail是并列展示所有渠道的汇总视图。
