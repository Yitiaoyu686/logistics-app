# Web 端实际页面盘点（MCP 实测）

## 说明

- 盘点时间：2026-03-20
- 盘点范围：`client/` Web 端
- 盘点方法：仅基于 MCP/Playwright 实际打开页面后的可见内容记录，包括列表页、已点开的详情页、编辑页、新增页、审批弹窗、抽屉/弹窗。
- 不纳入口径：仅存在于代码、但当前页面未实际展示的内容；未实际点开的隐藏分支；删除确认等破坏性动作。
- 导航状态实测数量：
  - 综合协同：25 个页面状态
  - 海运业务：25 个页面状态
  - 空运业务：25 个页面状态
  - 系统管理：19 个页面状态
