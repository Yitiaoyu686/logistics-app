## 1. CostReport 改造 → 承载 R1 毛利表

**现状**：340行，单表展示费用明细（feeNo/jobNo/feeType/amount/supplier/paymentStatus），按费用条目粒度，无毛利计算。

**改造方案**：增加 Tabs，保留原有"费用明细"Tab，新增"毛利表"Tab。

### 顶部筛选区（毛利表Tab专用）

| 筛选项 | 组件 | 选项 |
|--------|------|------|
| 月份 | DatePicker(month) | 2024-01 ~ 2024-12 |
| 运输方式 | Segmented | 空运 / 海运（联动 businessMode） |
| 目的地 | Select | LOS / NBO / JNB / ACC / 越南 / 全部 |
| 业务员 | Select(allowClear) | 黄颖/三凤/吕沛霖/朱小飞/... / 全部 |

**筛选**：月份（DatePicker month）

**表格列定义**：

| # | title | dataIndex | width | 说明 |
|---|-------|-----------|-------|------|

### Tab3：业务员明细

**筛选**：月份 + 业务员（Select）+ 运输方式（空运/海运）

**表格**：直接复用 R1 毛利表的全部列（31/32列），按选中业务员筛选展示。底部合计行。

### Tab4：发放确认单

**筛选**：月份 + 运输方式

**表格**：Tab1 或 Tab2 的提成总表数据，增加"领款人"列（签名用，导出时留空）

**操作按钮**：
- 生成发放单（导出PDF，含领款人签名栏、确认人、日期）
- 导出Excel
