## 阶段三：P0 页面开发（14页待开发）

### 第一批：核心操作页面（与货物物理接触）

- [ ] 6. 起运国仓管 — 扫码入库操作页
- [ ] 6.1 扫码匹配订单（相机扫快递条码 → 自动查询匹配 → 显示匹配结果/失败处理）
  - 匹配成功展示：运单号/客户/路线/收件人/已入库进度
  - 匹配失败三个选项：登记无单快递 / 手动输入运单号 / 继续扫描
  - 连续扫描模式：成功后0.5秒自动回到扫描页，底部统计今日件数
- [ ] 6.2 称重量方表单（实际件数/重量/长宽高 → 自动计算体积重和计费重量）
  - 运费参考：计费重量×单价=¥XXX
  - 包裹状况选择：正常/破损/受潮/拆封/少件，异常必须拍照(≥1张≤5张)
  - 库位号输入（可扫库位二维码）
- [ ] 6.3 确认入库并打印面单（调后端生成子运单 → 蓝牙打印100×150mm面单占位 → 震动音效反馈）
  - 后端接口：POST /api/v2/wms/inbounds
  - 异常时自动推送通知到操作员和销售

- [ ] 7. 起运国仓管 — 装箱与执行出库
- [ ] 7.1 (P) 添加订单到集装箱（扫码/搜索运单号 → 确认装入 → 更新进度条 → 容量超限提醒）
  - 后端接口：POST /api/warehouse/units/:id/load
- [ ] 7.2 (P) 绑定任务（未绑定JOB时，选择JOB任务绑定到线路）
- [ ] 7.3 执行出库表单（选择JOB → 发往地址姓名/电话/地址 → 拖车公司/送货单号/查询电话 → 司机名/电话/车牌 → 发货时间/备注 → 确认执行）
  - 拖车公司下拉数据来源：基础设置→供应商管理（type=TRUCKING）

- [ ] 8. 到达国仓管 — 配送签收与失败处理
- [ ] 8.1 (P) 配送完成/签收确认页（签收人姓名 + 拍照≥1张 + 到付收款金额和方式 + 备注 → 确认签收）
  - 后端接口：POST /api/v2/pod/delivery-tasks/:id/sign
- [ ] 8.2 (P) 配送失败页（原因选择：无人签收/地址错误/客户拒收/货物破损/其他 + 拍照 + 说明 → 提交）
  - 后端接口：POST /api/v2/pod/delivery-tasks/:id/fail
- [ ] 8.3 转为自提（确认弹窗 → 调后端创建自提记录 → 任务从配送列表移到自提列表）

- [ ] 9. 到达国仓管 — 自提管理
- [ ] 9.1 (P) 发送自提通知（一键发送短信含提货码+站点地址+营业时间 → 状态变已通知）
  - 后端接口：PUT /api/delivery/pickups/:id/notify
- [ ] 9.2 (P) 核销自提（验证提货码：扫码或手动输入 → 到付收款如有 → 确认提货 → 任务完成）
  - 后端接口：PUT /api/delivery/pickups/:id/complete
