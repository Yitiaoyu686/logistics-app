## 1. 工作台概览

**页面组件**: `WorkbenchOverview.tsx`

### 1.1 角色工作台（8 种）

| 角色编码 | 角色名称 | 说明 |
|---------|---------|------|
| `ADMIN` | 管理员 | 系统全局视图 |
| `SALES` | 销售 | 客户与订单视图 |
| `WAREHOUSE_CN` | 中国仓库 | 起运国仓储视图 |
| `OPS_CN` | 中国运营 | 起运国运营视图 |
| `OPS_US` | 海外运营 | 目的国运营视图 |
| `WAREHOUSE_US` | 海外仓库 | 目的国仓储视图 |
| `FINANCE` | 财务 | 费用与收支视图 |
| `BOSS` | 老板 | 宏观经营视图 |

根据当前登录用户角色，自动展示对应工作台。

### 1.2 通用工作台数据结构

| 字段 | 类型 | 说明 |
|------|------|------|
| `title` | string | 工作台标题 |
| `description` | string | 工作台描述 |
| `metrics` | MetricItem[] | 核心指标卡片列表 |
| `sections` | Section[] | 待办分组列表 |
| `progressTitle` | string | 进度区标题 |
| `progressItems` | ProgressItem[] | 进度项列表 |
| `quickActions` | QuickAction[] | 快捷操作按钮列表 |
| `notes` | string[] | 备忘/提示列表 |
| `taskProgressCards` | TaskProgressCard[] | 任务进度卡片列表 |
| `alertItems` | AlertItem[] | 预警项列表 |
| `notices` | string[] | 公告/通知列表 |

#### Section 结构

| 字段 | 类型 | 说明 |
|------|------|------|
| `sectionTitle` | string | 分组标题 |
| `items` | TodoItem[] | 待办项列表 |

### 1.3 TodoItem 结构

| 字段 | 类型 | 必填 | 说明 |

| 4 | 海关放行 | 海关放行通过 |

#### 目的国阶段

| 序号 | 节点 | 说明 |
|------|------|------|
| 6 | 已到港 | 到达目的港/机场 |
| 7 | 进口申报 | 提交进口申报 |
| 8 | 进口查验 | 进口海关查验 |
| 9 | 进口放行 | 进口海关放行 |
| 10 | 到达入仓 | 货物入目的国仓库 |
| 11 | 派送中 | 末端派送 |

### 1.6 预警类型枚举

| 枚举值 | 中文名 | 说明 |
|--------|--------|------|
| `ORDER_DELAY` | 订单延迟 | 订单处理超时 |
| `PAYMENT_OVERDUE` | 收款逾期 | 应收账款逾期 |
| `STOCK_ABNORMAL` | 库存异常 | 库存数据异常 |

| `TASK_ABNORMAL` | 任务异常 | 物流任务异常 |

### 1.7 各角色核心指标与待办分组

#### SALES（销售）

**核心指标**：我的客户数、未完成订单数、待收款金额、本月新增客户

**待办分组**：

| 分组 | 待办项示例 |
|------|----------|
| 我的客户 | 新客户待跟进、客户回访到期、客户流失预警 |
| 未完成订单 | 待报价订单、待确认订单、异常订单 |
| 待收款 | 应收逾期、本月到期应收、大额待收 |
| 本月新增 | 新增客户数、新增订单数、新增营收 |

#### WAREHOUSE_CN（中国仓库）

**核心指标**：待入库件数、在库货件数、无订单快递数、退运待处理数

**待办分组**：

| 分组 | 待办项示例 |
|------|----------|
| 待入库 | 今日预报到货、已到未入库、超时未入库 |
| 无订单快递 | 已签收无关联订单的快递件 |
| 退运待处理 | 待退运审批、待退运出库 |
| 在库货件 | 在库超期货件、待出库货件 |

#### FINANCE（财务）

**核心指标**：待审费用笔数、应收总额、应付总额、本月收款金额

**待办分组**：

| 分组 | 待办项示例 |
|------|----------|
| 待审费用 | 待审批费用单、待核销、待开票 |
| 应收 | 应收逾期、催收任务、坏账预警 |
| 应付 | 待付款、到期应付、供应商对账 |

#### BOSS（老板）

**核心指标**：本月营收、本月订单数、活跃客户数、毛利率、应收余额

以宏观经营指标为主，无具体待办分组，展示经营趋势和关键预警。

**页面组件**: `AlertCenter.tsx`

### 3.1 数据模型 — AlertItem

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `alertNo` | string | 是 | 预警编号 |
| `type` | enum | 是 | 预警类型 |
| `level` | enum | 是 | 严重程度 |
| `status` | enum | 是 | 处理状态 |
| `title` | string | 是 | 预警标题 |
| `description` | string | 是 | 预警描述 |
| `relatedType` | enum | 否 | 关联类型 |
| `relatedId` | number | 否 | 关联记录 ID |
| `relatedNo` | string | 否 | 关联单号 |
| `triggerTime` | datetime | 是 | 触发时间 |
| `resolvedTime` | datetime | 否 | 解决时间 |
| `resolvedBy` | number | 否 | 处理人 ID |
| `resolvedByName` | string | 否 | 处理人姓名 |
| `remark` | string | 否 | 备注 |

#### 预警类型枚举

| 枚举值 | 中文名 | Tag 颜色 |
|--------|--------|---------|
| `ORDER_DELAY` | 订单延迟 | `orange` |
| `PAYMENT_OVERDUE` | 收款逾期 | `red` |
| `STOCK_ABNORMAL` | 库存异常 | `purple` |
| `FEE_PENDING` | 费用待审 | `blue` |
| `CUSTOMS_DELAY` | 清关延迟 | `volcano` |

#### 严重程度枚举

| 枚举值 | 中文名 | Tag 颜色 |
|--------|--------|---------|
| `HIGH` | 高 | `red` |
| `MEDIUM` | 中 | `orange` |
| `LOW` | 低 | `blue` |

#### 处理状态枚举

| 枚举值 | 中文名 | Tag 颜色 |
|--------|--------|---------|
| `PENDING` | 待处理 | `default` |
| `PROCESSING` | 处理中 | `processing` |
| `RESOLVED` | 已解决 | `success` |
| `IGNORED` | 已忽略 | `default` |

#### 关联类型枚举

| 枚举值 | 中文名 |
|--------|--------|
| `ORDER` | 订单 |
| `JOB` | 任务 |
| `FEE` | 费用 |
| `STOCK` | 库存 |

### 3.2 统计卡片

| 指标 | 说明 |
|------|------|
| 待处理数 | `status = PENDING` 的预警总数 |
| 高优先级 | `level = HIGH` 且 `status = PENDING` 的数量 |
| 处理中 | `status = PROCESSING` 的数量 |

### 3.3 Tab 页签

| Tab | 说明 | Badge |
|-----|------|-------|
| 待处理 | `status = PENDING` | 显示数量 Badge |
| 处理中 | `status = PROCESSING` | — |
| 已解决 | `status = RESOLVED` | — |
| 已忽略 | `status = IGNORED` | — |
| 全部 | 所有状态 | — |

### 3.4 列表列定义

| 列名 | 说明 |
|------|------|
| 预警编号 | 文本 |
| 类型 | Tag 标签（按颜色映射） |
| 严重程度 | Tag 标签（按颜色映射） |
| 标题 | 文本 |
| 关联单号 | 文本 |
| 触发时间 | 日期时间 |
| 状态 | Tag 标签（按颜色映射） |
| 操作 | 详情 / 处理 / 忽略 |

### 3.5 操作规则

| 当前状态 | 可执行操作 | 目标状态 |
|---------|-----------|---------|
| `PENDING` | 处理 | `RESOLVED` |
| `PENDING` | 忽略 | `IGNORED` |

- **处理**：将状态变更为 `RESOLVED`，记录 `resolvedTime` 和 `resolvedBy`
- **忽略**：将状态变更为 `IGNORED`

### 3.6 详情弹窗

使用 `Descriptions` 组件展示 AlertItem 全部字段，包括：预警编号、类型、严重程度、状态、标题、描述、关联类型、关联单号、触发时间、解决时间、处理人、备注。

## 4. 报价计算器

**页面组件**: `PriceCalculator.tsx`

### 4.1 输入表单

| 字段 | 组件 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `country` | Select | 是 | — | 目的国：USA / UK / DE |
| `weight` | InputNumber | 是 | — | 重量（单位：kg） |
| `volume` | InputNumber | 否 | — | 体积（单位：m³） |
| `type` | Select | 否 | `NORMAL` | 货物类型：NORMAL 普货 / SENSITIVE 敏感货 |
| `transportType` | Select | 否 | `ALL` | 运输方式：ALL 全部 / AIR 空运 / SEA 海运 |

### 4.2 目的国选项

| 枚举值 | 国家 |
|--------|------|
| `USA` | 美国 |
| `UK` | 英国 |
| `DE` | 德国 |

### 4.3 结果列表列定义

| 列名 | 说明 |
|------|------|
| 渠道名称 + tags | 渠道名称 + 运输方式/时效等标签 |
| 时效 | 预计运输天数 |
| 单价 | 元/kg |
| 预估总价 | ¥金额，**红色加粗** |
| 操作 | 复制报价文案 |

### 4.4 复制报价文案格式

```
【报价】{channel}
时效：{etd}
单价：¥{pricePerKg}/kg
预估总价：¥{totalPrice}
```

点击「复制报价文案」后，按上述格式生成文本并复制到剪贴板，提示"复制成功"。

### 4.5 排序规则

| 排序方式 | 说明 |
|---------|------|
| 价格从低到高 | 按预估总价升序 |
| 时效从快到慢 | 按时效天数升序 |

默认按价格从低到高排序，用户可切换排序方式。
