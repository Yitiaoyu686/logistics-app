## 1. 创建/编辑任务表单

> **业务描述**
> 运输任务(JOB)是连接起运国仓储和到达国仓储的核心单据。起运国操作人员在仓库完成装箱后，创建JOB任务并录入船务/航班信息，安排国际运输。
> - **角色**: 起运国操作(OPS_CN)、管理员(ADMIN)
> - **前置条件**: 起运国仓储已完成装箱(集装箱/集装号已封箱)
> - **海运vs空运**: 海运填写船务信息(提单号/船公司/柜型/起运港→目的港/截关日期/开船日期)；空运填写航班信息(主运单号/航空公司/航班号/起飞机场→目的机场/截单时间)
> - **数据来源**: 集装箱/集装号(WMS任务执行绑定)、承运商/港口(系统设置)
> - **数据去向**: JOB创建后→集装箱绑定JOB号→起运国操作更新物流节点→到达国操作接收并继续更新节点→到达国仓库按JOB入库
> - **关键关系**: 一个JOB关联多个集装箱/集装号，每个集装箱装载多个子运单

## 2. 任务列表

> **业务描述**
> 起运国办和到达国办各有一个任务管理列表。起运国办管理从创建到发运的阶段，到达国办管理从到港到签收的阶段。两个列表共享同一批JOB数据，但显示不同的操作按钮。
> - **起运国vs到达国区别**: 起运国有创建/编辑/删除/成本录入操作；到达国只有节点更新/详情/暂停操作。列名：海运显示"集装箱"、空运显示"集装号"。

## 3. 任务状态

### 3.1 状态枚举

| 枚举值 | 中文名称 | 标签颜色 | 说明 |
|--------|---------|---------|------|
| `PENDING` | 待执行 | warning | 任务创建初始状态 |
| `IN_PROGRESS` | 执行中 | processing | 任务正在执行 |
| `COMPLETED` | 已完成 | success | 任务全部节点完成 |
| `SUSPENDED` | 已暂停 | red | 任务被暂停 |

### 3.2 状态流转

```
PENDING → IN_PROGRESS → COMPLETED
   ↓           ↓
   └───→ SUSPENDED ←───┘
              ↓
         IN_PROGRESS（恢复）
```

- 首次节点更新时：`PENDING` → `IN_PROGRESS`
- 全部节点完成时：`IN_PROGRESS` → `COMPLETED`
- 任意非完成状态可暂停：`*` → `SUSPENDED`
- 恢复操作：`SUSPENDED` → `IN_PROGRESS`

## 4. 节点更新

> **业务描述**
> 物流节点是跟踪货物位置的关键信息，每次状态变更都需要操作人员手动更新。节点更新会推送到订单详情的物流状态栏，客户和销售可以看到最新位置。
> - **起运国节点流**: 已离库→出口报关→海关查验→海关放行→已起运（共5个）
> - **到达国节点流**: 已到港→进口申报→进口查验→进口放行→到达入仓→派送中→已签收（共7个）
> - **数据去向**: 节点更新写入JOB的节点记录→同步到订单详情的物流状态栏→工作台的任务进展卡片
> - **首次更新**: 首次节点更新时，JOB状态自动从"待执行"变为"执行中"
> - **异常标记**: 可标记某个节点存在异常(如海关查验异常)，异常信息会在任务列表中高亮显示

### 4.1 起运国节点流

| 序号 | 节点代码 | 中文名称 | 说明 |
|------|---------|---------|------|
| 1 | `WAREHOUSE_OUT` | 已离库 | 货物离开仓库 |
| 2 | `CUSTOMS_EXPORT` | 出口报关 | 提交出口报关 |
| 3 | `CUSTOMS_CHECK` | 海关查验 | 海关实施查验 |
| 4 | `CUSTOMS_RELEASE` | 海关放行 | 海关放行通过 |
| 5 | `DEPARTURE` | 已起运 | 货物离港/离港 |

| 3 | `IMPORT_CUSTOMS_CHECK` | 进口查验 | 海关进口查验 |

## 5. 暂停与恢复

> **业务描述**
> 运输过程中遇到客户要求、付款问题、海关查验、船期变更等情况时，需要暂停任务的所有操作。暂停后节点更新和成本录入按钮禁用，编辑/删除按钮隐藏。
> - **数据影响**: JOB状态→SUSPENDED，关联的订单操作也受影响
> - **恢复**: 恢复后状态变回"执行中"

### 5.1 暂停 Modal

| 字段名 | 字段标识 | 组件类型 | 必填 | 说明 |
|--------|---------|---------|------|------|
| 暂停原因 | suspendReason | Select | 是 | 见暂停原因选项 |
| 暂停备注 | suspendRemark | TextArea | 否 | 补充说明 |

**暂停原因选项：**

| 枚举值 | 中文名称 |
|--------|---------|
| `CUSTOMER_REQUEST` | 客户要求 |
| `PAYMENT_ISSUE` | 付款问题 |
| `CUSTOMS_INSPECTION` | 海关查验 |
| `DOCUMENT_INCOMPLETE` | 单证不齐 |
| `CARGO_ISSUE` | 货物问题 |
| `SCHEDULE_CHANGE` | 船期/航班变更 |
| `INTERNAL_DISPATCH` | 内部调度 |
| `OTHER` | 其他 |

### 5.2 暂停效果

- 任务状态变更为 `SUSPENDED`
- 节点更新按钮 **禁用**
- 成本录入按钮 **禁用**
- 编辑按钮 **隐藏**
- 删除按钮 **隐藏**

### 5.3 恢复效果

- 任务状态变更为 `IN_PROGRESS`
- 所有操作按钮恢复正常显示

## 6. JOB 成本录入（POL + POD）

> **业务描述**
> JOB成本是运输环节产生的各项费用，分为起运国成本和到达国成本。起运国成本以CNY为主(订舱/报关/拖车等)，到达国成本以NGN/USD为主(清关/关税/港杂/配送等)。成本录入是财务核算毛利的基础数据。
> - **角色**: 起运国操作(OPS_CN)录入起运国成本，到达国操作(OPS_US)录入到达国成本
> - **操作模式**: 每个JOB一条记录，下挂多条费用条目。条目可选归属层级(JOB公摊/集装箱公摊/订单号/子单号)
> - **审核流程**: 草稿→提交审核(条目→PENDING)→主管逐条审核(APPROVED/REJECTED)→自动推导任务状态。已审核条目不可直接修改，需"申请修改"生成CHANGE行。
> - **数据去向**: 审核通过的费用→汇入财务中心费用管理→应付管理→毛利表成本列

## 9. 成本审核流程

> POL 成本、POD 成本、DPN 成本、订单费用（OrderFee）共用同一套审核流程。

### 9.1 任务级审核状态

| 枚举值 | 中文名称 | 说明 |
|--------|---------|------|
| `DRAFT` | 草稿 | 初始录入状态 |
| `PENDING_SUPERVISOR` | 待主管审核 | 已提交审核 |
| `APPROVED` | 已审核通过 | 全部条目通过 |
| `REJECTED` | 已驳回 | 全部条目驳回 |
| `PART_REJECTED` | 部分驳回 | 部分条目驳回 |

### 9.2 条目级审核状态

| 枚举值 | 中文名称 | 说明 |
|--------|---------|------|
| `DRAFT` | 草稿 | 初始状态 |
| `PENDING` | 待审核 | 已提交待审 |
| `APPROVED` | 已通过 | 审核通过 |
| `REJECTED` | 已驳回 | 审核驳回 |

### 9.3 审核流程

```
录入 → 保存草稿(DRAFT) → 提交审核(→PENDING_SUPERVISOR, 条目→PENDING)
  → 主管逐条审核(APPROVED / REJECTED + 审核意见)
  → 自动推导任务级审核状态
```

**任务级状态自动推导规则：**

| 条目审核结果 | 任务级状态 |
|-------------|----------|
| 全部通过 | `APPROVED` |
| 全部驳回 | `REJECTED` |
| 部分通过、部分驳回 | `PART_REJECTED` |

### 9.4 已审核条目修改

1. 已审核通过的条目 **不可直接编辑**
2. 需点击"申请修改"按钮
3. 系统自动生成一条 `CHANGE` 行（kind=CHANGE），包含 `originalSnapshot` 原始快照
4. CHANGE 行走同样的审核流程
5. 审核通过后，原始行变为历史记录

### 9.5 编辑规则

| 条目状态 | 可否编辑 | 说明 |
|---------|---------|------|
| `DRAFT` | 可编辑 | 自由修改 |
| `PENDING` | 不可编辑 | 审核中锁定 |
| `APPROVED` | 不可编辑 | 只能通过"申请修改"生成 CHANGE 行 |
| `REJECTED` | 可编辑 | 修改后可重新提交 |
| 有未处理 CHANGE 的 NORMAL 行 | 不可编辑 | 等待 CHANGE 审核完成 |
