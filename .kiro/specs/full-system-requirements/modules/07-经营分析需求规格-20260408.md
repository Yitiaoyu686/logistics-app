## 1. 经营看板

**页面组件**: `ExecutiveDashboard.tsx`

### 1.1 时间维度切换

| 切换项 | 说明 |
|--------|------|
| 本月 | 当前自然月数据 |
| 本季度 | 当前自然季度数据 |
| 本年 | 当前自然年数据 |

切换时所有 KPI 和排名表同步刷新。

### 1.2 KPI 第一行 — 营收指标

| 指标 | 数据格式 | 说明 |
|------|---------|------|
| 本期营收 | ¥金额 + 同比 YoY% | 同比上升绿色箭头、下降红色箭头 |
| 本期成本 | ¥金额 + 同比 YoY% | **成本上升 = 红色**（逆向指标） |
| 本期毛利 | ¥金额 + 同比 YoY% | 同比上升绿色、下降红色 |
| 毛利率 | 百分比% | 目标值 25%，达标/未达标标签 |

#### 毛利率计算公式

```
毛利率 = (revenue - cost) / revenue × 100
```

#### 毛利率颜色规则

| 条件 | 颜色 | 说明 |
|------|------|------|
| `>= 20%` | 绿色 `green` | 健康 |
| `>= 10%` 且 `< 20%` | 橙色 `orange` | 警告 |
| `< 10%` | 红色 `red` | 危险 |

### 1.3 KPI 第二行 — 运营指标

| 指标 | 单位 | 说明 |
|------|------|------|
| 订单量 | 单 | 本期订单总数 |
| 任务完成量 | 个 | 本期完成的物流任务数 |
| 活跃客户数 | 家 | 本期有订单的客户数 |
| 应收余额 | ¥金额 + 逾期¥ | 逾期金额以**红色**显示 |

### 1.4 业务员排名表

| 列名 | 说明 |
|------|------|
| 排名 | 前 3 名显示金🥇银🥈铜🥉奖杯图标 |
| 业务员 | 业务员姓名 |
| 营收 | ¥金额 |
| 毛利 | ¥金额，正值绿色、负值红色 |
| 毛利率 | 百分比，按颜色规则（>=20%绿/>=10%橙/<10%红） |
| 订单数 | 数量 |
| 客户数 | 数量 |

默认按营收降序排列。

### 1.5 路线排名表

| 列名 | 说明 |
|------|------|
| 排名 | 序号 |
| 路线 | 起运地 → 目的地 |
| 营收 | ¥金额 |
| 毛利 | ¥金额 |
| 毛利率 | 百分比，按颜色规则 |
| 任务数 | 数量 |
| 运输方式 | Tag 标签：海运 `blue` / 空运 `cyan` |

默认按营收降序排列。

### 1.6 底部经营风险提示

使用 Ant Design `Alert` 组件，展示当前经营风险提示信息，类型为 `warning`，支持多条风险提示列表展示。

## 2. 客户价值分析

**页面组件**: `CustomerValueAnalysis.tsx`

### 2.1 统计卡片（6 个）

| 指标 | 数据格式 | 说明 |
|------|---------|------|
| 客户总数 | 数字 | 系统全部客户 |
| 本期活跃客户 | 数字 | 本期有订单的客户 |

| 流失预警数 | 数字 | 超过一定天数未下单的客户 |

### 2.2 筛选条件

| 筛选项 | 类型 | 选项 |
|--------|------|------|
| 时间范围 | DateRangePicker | 自定义起止日期 |
| 行业 | Select | 全部 / 电商 / 贸易 / 工厂 / 个人 |
| 业务员 | Select | 5 名业务员 |
| 客户等级 | Select | A（gold）/ B（blue）/ C（default）/ D（red） |

### 2.3 主表列定义

| 列名 | 排序 | 说明 |
|------|------|------|
| 客户名称 | — | 文本 |
| 客户等级 | — | Tag 标签（A=gold / B=blue / C=default / D=red） |
| 行业 | — | 文本 |
| 业务员 | — | 文本 |
| 累计营收 | ↕ 可排序（默认降序） | ¥金额 |
| 累计毛利 | ↕ 可排序 | ¥金额 |
| 毛利率 | ↕ 可排序 | 百分比% |
| 订单数 | ↕ 可排序 | 数字 |
| 最近下单 | — | 日期，**超过 60 天红色**显示 |
| 应收余额 | ↕ 可排序 | ¥金额，**> 0 红色**显示 |
| 操作 | — | 详情按钮 |

### 2.4 详情抽屉（Drawer，4 个 Tab）

#### Tab 1: 基本信息

展示 9 个字段：客户名称、客户等级、行业、业务员、联系人、联系电话、地址、注册日期、备注。使用 `Descriptions` 组件布局。

#### Tab 2: 营收趋势

月度明细表：

| 列名 | 说明 |
|------|------|
| 月份 | YYYY-MM 格式 |
| 收入 | ¥金额 |
| 成本 | ¥金额 |
| 利润 | ¥金额 |
| 毛利率 | 百分比% |
| 订单数 | 数字 |

底部显示**合计行**。

#### Tab 3: 订单明细

| 列名 | 说明 |
|------|------|
| 运单号 | 支持**点击复制** |
| 下单日期 | 日期 |
| 路线 | 起运地 → 目的地 |
| 运输方式 | Tag 标签（海运/空运） |
| 金额 | ¥金额 |
| 状态 | Tag 标签（各订单状态） |

#### Tab 4: 费用概况

**统计区域**：应收总额、已收总额、逾期总额

**费用分类表**：

| 列名 | 说明 |
|------|------|
| 费用分类 | 类别名称 |
| 金额 | ¥金额 |
| 占比 | 百分比% |
| 笔数 | 数字 |
