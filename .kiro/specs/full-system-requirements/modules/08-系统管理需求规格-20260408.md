## 1. 仓库管理

**页面组件**: `WarehouseManagement.tsx`

### 1.1 数据模型 — Warehouse

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `id` | number | 是 | 主键 |
| `code` | string | 是 | 仓库编码，唯一标识 |
| `name` | string | 是 | 仓库名称（中文） |
| `nameEn` | string | 否 | 仓库名称（英文） |
| `type` | enum | 是 | 仓库类型：`ORIGIN` 起运国 / `DESTINATION` 到达国 / `TRANSIT` 中转 |
| `country` | string | 是 | 所在国家 |
| `city` | string | 是 | 所在城市 |
| `siteId` | number | 否 | 所属站点 ID |
| `siteName` | string | 否 | 所属站点名称 |
| `siteType` | enum | 否 | 站点类型：`HQ` 总部 / `DISPATCH_CENTER` 调度中心 / `SATELLITE` 卫星站 |
| `address` | string | 否 | 详细地址 |
| `managerId` | number | 否 | 负责人用户 ID |
| `managerName` | string | 否 | 负责人姓名 |
| `managerPhone` | string | 否 | 负责人电话 |
| `capacity` | number | 否 | 容量（单位：m³） |
| `status` | enum | 是 | 状态：`ACTIVE` 启用 / `INACTIVE` 停用 |
| `remark` | string | 否 | 备注 |
| `createdAt` | datetime | 是 | 创建时间 |
| `updatedAt` | datetime | 否 | 更新时间 |

### 1.2 统计卡片

| 指标 | 说明 |
|------|------|
| 总仓库数 | 全部仓库数量 |
| 起运国 | `type = ORIGIN` 的数量 |
| 到达国 | `type = DESTINATION` 的数量 |
| 中转 | `type = TRANSIT` 的数量 |

### 1.3 筛选条件

| 筛选项 | 类型 | 说明 |
|--------|------|------|
| 仓库类型 | Select | ORIGIN / DESTINATION / TRANSIT |
| 状态 | Select | ACTIVE / INACTIVE |
| 国家 | Select | 国家列表 |
| 站点 | Select | 站点列表 |

### 1.4 列表列定义

| 列名 | 宽度 | 说明 |
|------|------|------|
| 仓库编码 | 120px | 文本 |
| 仓库名称 | 180px | 文本 |
| 类型 | 100px | Tag 标签（ORIGIN/DESTINATION/TRANSIT） |
| 国家城市 | 150px | 国家 + 城市 |
| 所属站点 | 160px | 站点名称 |
| 负责人 + 电话 | 140px | 姓名 + 电话号码 |
| 容量 | 100px | 数字（单位 m³） |
| 状态 | 100px | Switch 开关 |
| 操作 | 150px | 编辑 / 删除 |

### 1.5 新增/编辑表单

| 字段 | 组件 | 校验规则 |
|------|------|---------|
| `code` | Input | 必填，**编辑时禁用** |
| `name` | Input | 必填 |
| `nameEn` | Input | 选填 |

| 角色名称 | 文本 |
| 站点范围 | Tag 标签 |
| 状态 | Tag 标签 |
| 权限数 | 数字 |
| 用户数 | 数字 |
| 描述 | 文本 |
| 操作 | 查看 / 编辑 / 删除 |

### 3.3 新增/编辑表单

| 字段 | 组件 | 校验规则 |
|------|------|---------|
| `roleCode` | Input | 必填，**编辑时禁用** |
| `roleName` | Input | 必填 |
| `siteScope` | Select | 必填 |
| `status` | Select | 必填 |
| `description` | TextArea | 选填 |

### 3.4 权限分配

- 使用 `Checkbox.Group` 展示所有可分配权限
- 每个选项显示：权限名称（`permissionName`）+ 权限编码（`Code`）
- 2 列网格布局（`Grid`）

### 3.5 删除限制

| 限制条件 | 提示信息 |
|---------|---------|
| 系统内置角色 `isSystem = true` | 不可删除，按钮禁用或隐藏 |
| 关联用户数 `userCount > 0` | 不可删除，提示"该角色已关联用户，无法删除" |

### 3.6 详情弹窗

- 使用 `Descriptions` 组件展示角色基本信息
- 底部展示已分配权限 Tag 列表

|------|------|------|
| `name` | string | 规则名称 |
| `transportMode` | enum | 运输方式（AIR/SEA_LCL） |
| `currency` | string | 计费货币 |
| `unitPrice` | number | 单价 |
| `unitType` | string | 计费单位 |
| `minCharge` | number | 最低收费（可选） |
| `remark` | string | 备注（可选） |
| `status` | enum | 状态 |

#### 空运专属参数

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `volumetricDivisor` | number | 6000 | 体积重除数 |
| `firstWeightPrice` | number | — | 首重单价 |
| `continuationTiers` | object[] | — | 续重阶梯：`[{minWeight, maxWeight, unitPrice}]` |
| `surchargeRates` | object | — | 品类附加费率：`{品类名: 百分比}` |
| `packagingSurchargePerKg` | number | — | 木箱包装附加费（每公斤） |

#### 海运专属参数

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `volumeWeightRatio` | number | 700 | 体积重比率（1m³ = 700kg） |
| `unitPricePerCBM` | number | — | 每立方米单价 |

### 13.3 空运计费逻辑

```
1. 体积重 = 长(cm) × 宽(cm) × 高(cm) / volumetricDivisor
2. 计费重 = max(实际重量, 体积重)
3. 首重部分使用 firstWeightPrice
4. 续重部分按 continuationTiers 阶梯价计费
5. 非普货类别加收 surchargeRates 中对应品类附加费率
6. 木箱包装加收 packagingSurchargePerKg × 计费重
```

### 13.4 海运计费逻辑

```
1. 1m³ = volumeWeightRatio kg
2. 体积重 = 体积(m³) × volumeWeightRatio
3. 计费重 = max(实际重量, 体积重)
4. 按较大值计费
```

| `reason` | string | 调薪原因 |

### 18.2 月薪计算公式

```
月薪合计 = baseSalary + positionAllowance + mealAllowance + transportAllowance
```

### 18.3 统计卡片

| 指标 | 说明 |
|------|------|
| 在职人数 | `status = ACTIVE` 的人数 |
| 月薪总额 | 全部在职员工月薪合计之和 |
| 社保 + 公积金公司月缴 | 全部在职员工公司缴社保 + 公积金合计 |
| 平均月薪 | 月薪总额 / 在职人数 |
