## 1. 仓库管理

> **业务描述**
> 管理公司在全球的仓库网络。分为起运国仓库(中国广州/深圳/上海)、到达国仓库(尼日利亚拉各斯/阿布贾、加纳阿克拉)、中转仓库(卡诺/哈科特港)。每个仓库归属一个站点，站点决定了用户的数据权限范围。
> - **关联关系**: 仓库→站点→用户。用户只能看到其所属站点的数据。仓库选择器(右上角"全部仓库"下拉)控制当前操作范围。
> - **数据去向**: 仓库和站点数据被WMS入库/库存引用(入库到哪个仓库)、被TMS引用(操作站点)、被用户管理引用(分配站点)

**页面组件**: `WarehouseManagement.tsx`

## 2. 用户管理

> **业务描述**
> 管理系统所有用户账号。每个用户分配角色(决定可见菜单和操作权限)和站点(决定可见数据范围)。系统预设8个业务角色+1个预留角色。
> - **数据去向**: 用户信息被登录认证引用、被CRM的salesId引用(业务员)、被财务的薪资/提成引用

## 3. 角色管理

> **业务描述**
> RBAC权限模型。角色定义了用户可以访问的模块和操作。权限分为4类: MENU(菜单可见)、TAB(页签可见)、BUTTON(按钮可用)、API(接口可调)。系统内置角色不可删除。
> - **站点范围**: 全站点(ALL_SITE,如ADMIN/BOSS看所有数据)、分配站点(ASSIGNED_SITE,只看分配的站点数据)

**页面组件**: `RoleManagement.tsx`

### 3.1 数据模型 — RbacRole

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `id` | number | 是 | 主键 |
| `roleCode` | string | 是 | 角色编码，唯一 |
| `roleName` | string | 是 | 角色名称 |
| `description` | string | 否 | 描述 |
| `siteScope` | enum | 是 | 站点范围：`ALL_SITE` 全站 / `ASSIGNED_SITE` 分配站 / `OWN_SITE` 本站 |
| `status` | enum | 是 | 状态：`ACTIVE` / `INACTIVE` |
| `isSystem` | boolean | 是 | 是否系统内置角色 |
| `userCount` | number | 是 | 关联用户数 |
| `permissionCount` | number | 是 | 已分配权限数 |
| `createdAt` | datetime | 是 | 创建时间 |

### 3.2 列表列定义

| 列名 | 说明 |
|------|------|
| 角色编码 | 文本 + 系统内置标签（`isSystem = true` 时） |
| 角色名称 | 文本 |
| 站点范围 | Tag 标签 |
| 状态 | Tag 标签 |
| 权限数 | 数字 |
| 用户数 | 数字 |
| 描述 | 文本 |
| 操作 | 查看 / 编辑 / 删除 |

### 3.3 新增/编辑表单

| 字段 | 组件 | 校验规则 |
|------|------|---------|
| `roleCode` | Input | 必填，**编辑时禁用** |
| `roleName` | Input | 必填 |
| `siteScope` | Select | 必填 |
| `status` | Select | 必填 |
| `description` | TextArea | 选填 |

### 3.4 权限分配

- 使用 `Checkbox.Group` 展示所有可分配权限
- 每个选项显示：权限名称（`permissionName`）+ 权限编码（`Code`）
- 2 列网格布局（`Grid`）

### 3.5 删除限制

| 限制条件 | 提示信息 |
|---------|---------|
| 系统内置角色 `isSystem = true` | 不可删除，按钮禁用或隐藏 |
| 关联用户数 `userCount > 0` | 不可删除，提示"该角色已关联用户，无法删除" |

### 3.6 详情弹窗

- 使用 `Descriptions` 组件展示角色基本信息
- 底部展示已分配权限 Tag 列表

## 7. 线路管理

## 13. 运费规则

> **业务描述**
> 定义空运和海运拼箱的运费计算规则。空运按首重+续重阶梯计费(含体积重换算和品类附加费)；海运按体积和重量较大值计费。规则被OMS预估运费和WMS入库时运费计算引用。
> - **计费逻辑**: 空运: 计费重=max(实重, 长×宽×高/6000), 首重用首重价, 续重按阶梯; 海运: 1m³=700kg换算, 按较大值×单价

**页面组件**: `FreightRateRule.tsx`

### 13.1 运输方式

| 枚举值 | 中文名 |
|--------|--------|
| `AIR` | 航空 |
| `SEA_LCL` | 海运拼箱 |

### 13.2 数据模型 — FreightRateRule

| 字段 | 类型 | 说明 |
|------|------|------|
| `name` | string | 规则名称 |
| `transportMode` | enum | 运输方式（AIR/SEA_LCL） |
| `currency` | string | 计费货币 |
| `unitPrice` | number | 单价 |
| `unitType` | string | 计费单位 |
| `minCharge` | number | 最低收费（可选） |
| `remark` | string | 备注（可选） |
| `status` | enum | 状态 |

#### 空运专属参数

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `volumetricDivisor` | number | 6000 | 体积重除数 |
| `firstWeightPrice` | number | — | 首重单价 |
| `continuationTiers` | object[] | — | 续重阶梯：`[{minWeight, maxWeight, unitPrice}]` |
| `surchargeRates` | object | — | 品类附加费率：`{品类名: 百分比}` |
| `packagingSurchargePerKg` | number | — | 木箱包装附加费（每公斤） |

#### 海运专属参数

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `volumeWeightRatio` | number | 700 | 体积重比率（1m³ = 700kg） |
| `unitPricePerCBM` | number | — | 每立方米单价 |

### 13.3 空运计费逻辑

```
1. 体积重 = 长(cm) × 宽(cm) × 高(cm) / volumetricDivisor
2. 计费重 = max(实际重量, 体积重)
3. 首重部分使用 firstWeightPrice
4. 续重部分按 continuationTiers 阶梯价计费
5. 非普货类别加收 surchargeRates 中对应品类附加费率
6. 木箱包装加收 packagingSurchargePerKg × 计费重
```

### 13.4 海运计费逻辑

```
1. 1m³ = volumeWeightRatio kg
2. 体积重 = 体积(m³) × volumeWeightRatio
3. 计费重 = max(实际重量, 体积重)
4. 按较大值计费
```

## 20. 推送模板

> **业务描述**

## 21. 短信推送

> **业务描述**
> 记录和管理系统发送的所有短信。短信来源分为两类：① 自动触发 — 由推送模板配置的事件自动发送（如派送通知、到港通知）；② 手动发送 — 管理员手动填写内容发送。支持按业务模块、接收人类型、发送状态等维度查询和统计。
> - **关联关系**: 短信记录 ← 推送模板（自动触发时）。短信可关联业务单号（订单号、任务号、DPN号等）。
> - **数据去向**: 短信发送日志、费用统计

**页面组件**: `MessageNotification.tsx` — `SmsPushManagement`

### 21.1 数据模型 — SmsRecord

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `id` | string | 是 | 记录ID |
| `phone` | string | 是 | 手机号（支持国际号码） |
| `recipientName` | string | 是 | 接收人名称 |
| `recipientType` | enum | 是 | 接收人类型 |
| `templateCode` | string | 是 | 模板编码（手动发送为 MANUAL） |
| `templateName` | string | 是 | 模板名称 |
| `module` | enum | 是 | 关联业务模块 |
| `relatedNo` | string | 否 | 关联业务单号 |
| `content` | string | 是 | 短信内容 |
| `status` | enum | 是 | 发送状态 |
| `sentAt` | datetime | 否 | 发送时间 |
| `createdAt` | datetime | 是 | 创建时间 |
| `createdBy` | string | 是 | 创建人（"系统自动"或操作人用户名） |
| `errorMsg` | string | 否 | 失败原因 |
| `cost` | number | 否 | 短信费用（元） |

#### 接收人类型枚举

| 值 | 说明 | 典型场景 |
|------|------|---------|
| `STAFF` | 内部员工 | 系统通知、审批提醒、预警 |
| `CUSTOMER` | 客户 | 订单状态、派送通知、签收确认 |
| `CARRIER` | 承运人 | 发车确认、运力调度 |
| `DRIVER` | 司机 | 派送任务分配、路线指引 |

#### 发送状态枚举

| 值 | 说明 | 可用操作 |
|------|------|---------|
| `PENDING` | 发送中 | — |
| `SENT` | 已送达 | 删除 |
| `FAILED` | 失败 | 重发、删除 |
| `REJECTED` | 被拒（运营商拒绝） | 删除 |
