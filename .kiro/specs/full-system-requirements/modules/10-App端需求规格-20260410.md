### 1.2 App 设计原则

- **待办驱动** — 打开App看到"今天要干什么"，点击待办→执行→完成→下一个，不需要在菜单里找功能
- **Web 有什么，App 就有什么** — 三个角色在 Web 端能操作的功能，App 端都要能完成
- **扫码一键直达** — 底部中央凸起的扫码按钮，随时随地一键打开相机
- **与货物接触的操作优先** — 扫码入库、称重量方、打印面单、装箱封箱、签收拍照，必须在现场一站式完成
- **单手操作** — 一手拿货，一手操作手机，按钮≥48px
- **3步完成** — 高频操作（扫码→确认→下一件）不超过3步
- **离线可用** — 扫码、拍照、签收等操作离线执行，联网后自动同步

### 1.3 待办驱动架构

```
┌────────────────────────────────────────────┐
│  App首页 = 待办列表                          │
│  ┌──────────────────────────────────────┐  │
│  │ 📌 待入库运单 3票            → 去处理   │  │
│  │ 📌 调拨到仓待处理 1票        → 去处理   │  │
│  │ 📌 已分配待装箱 5件          → 去处理   │  │
│  │ 📌 无订单快递待处理 2件      → 去处理   │  │
│  └──────────────────────────────────────┘  │
│  点击"去处理" → 直接进入操作页面             │
│  完成操作 → 自动回到待办列表                 │
│  待办数量实时更新                             │
└────────────────────────────────────────────┘
```

用户不需要记住功能在哪个菜单下，**待办会告诉你该做什么，点击就去做**。

### 1.4 底部导航设计（5 Tab + 中央凸起扫码）

**仓管CN端 / 仓管US端**（统一结构）
```
                    ┌─────┐
[ 任务 ] [ 查询 ]  │ 📷  │  [ 消息 ] [ 我的 ]
                    └─────┘
```
- **任务** = 任务卡片流（所有待处理事项直接展示为可操作卡片，按类型Tab筛选）
- **查询** = 库存查询/入库记录/订单查询等信息检索
- **📷 扫码**（中央凸起按钮）= 万能扫码入口，自动识别跳转
- **消息** = 通知中心（未读红点）
- **我的** = 个人中心+打印机设置（仓管CN）

**销售端**
```
                    ┌─────┐
[ 待办 ] [ 客户 ]  │  +  │  [ 订单 ] [ 我的 ]
                    └─────┘
```
- **待办** = 今日任务列表（客户待跟进/未完成订单/待收款/逾期应收…）
- **客户** = 客户中心（我的客户+公海池）
- **+ 快捷操作**（中央凸起按钮）= 弹出快捷菜单：新建订单 / 运费试算 / 扫码查单
- **订单** = 订单列表
- **我的** = 个人中心+消息

### 1.5 扫码按钮的智能识别

仓管角色的中央扫码按钮不是只做入库，它是**万能扫码入口**：

| 扫到什么 | 识别结果 | 自动跳转 |
|---------|---------|---------|
| 快递单条码 | 匹配到订单 | → 入库操作页（称重→打印面单） |
| 快递单条码 | 未匹配 | → 无单快递登记页 |
| 运单号/面单QR码 | 在库货物 | → 库存详情页（可补打面单/改库位） |
| 集装箱号条码 | 集装箱 | → 装箱操作页（扫码装入） |
| 调拨单条码 | 调拨单 | → 调拨详情页 |
| 提货码 | 自提记录 | → 自提核销页（仓管US） |
| 无法识别 | — | → 手动输入框 |

一个扫码按钮覆盖所有扫码场景，系统自动识别跳转。

#### 2.3.2 新建订单

> 对应 Web：OrderCreate 多步骤表单，App做简化适配

**步骤1：选客户 + 基础信息**

| 字段 | 控件 | 说明 |
|------|------|------|
| 客户 | 搜索选择 | 选中后自动填充发货人/收货人/路线/付款方式 |
| 服务类型 | 下拉 | 特快/普快 |
| 出口方式 | 下拉 | 买单出口/自备单证 |
| 付款方式 | 下拉 | 预付/到付 |

**步骤2：填写快递包裹**

每个包裹：
| 字段 | 控件 | 必填 |
|------|------|------|
| 快递公司 | 下拉 | 是 |
| 快递单号 | Input + 扫码按钮📷 | 是 |
| 品名 | Input | 是 |
| 品类 | 下拉 | 否 |
| 货物属性 | 普货/敏感 | 否 |
| 件数 | 数字 | 是 |
| 重量(kg) | 数字 | 否 |
| 长×宽×高(cm) | 数字 | 否 |

- "+" 添加更多包裹
- 扫码按钮：调用相机扫快递条码自动填入单号+识别快递公司

**步骤3：确认收货信息**
- 发货人（从客户档案带入，可修改）
- 收货人（从客户档案带入，可修改/选择其他收货人）

**步骤4：确认提交**
- 汇总：客户 · 件数 · 预估运费
- 入仓号（自动生成）
- 提交

**成功页**
- 运单号（可复制）· 入仓号（可复制/分享）
- 继续创建 | 查看订单 | 返回
