| | | 到达国仓储 | 任务入库、DPN入库、库存查询、DPN管理、配送列表、自提列表 |

### 1.2 App 设计原则

- **Web 有什么，App 就有什么** — 三个角色在 Web 端能操作的功能，App 端都要能完成
- **与货物产生物理接触的操作优先** — 扫码入库、称重量方、打印面单、装箱封箱、签收拍照，这些必须在现场一站式完成
- **单手操作** — 一手拿货/扫码枪，一手操作手机
- **3步完成** — 高频操作（扫码→确认→下一件）不超过3步
- **离线可用** — 扫码、拍照、签收等操作离线执行，联网后自动同步

### 1.3 底部导航设计

**销售端**（4 Tab）
```
[ 工作台 ] [ 客户 ] [ 订单 ] [ 我的 ]
```
- 工作台 = Web 的工作台（统计+待办+预警+任务进展+通知公告）

- 我的 = 个人中心+消息中心

**仓管CN端**（4 Tab）
```
[ 工作台 ] [ 入库 ] [ 仓库 ] [ 我的 ]
```
- 工作台 = Web 的工作台（统计+待办+预警+任务进展+通知公告）
- 入库 = 快递扫码入库（扫码→称重→打印面单→上架，核心高频操作）
- 仓库 = Web 的起运国仓储 8 个 Tab 全部收在这里
- 我的 = 个人中心+消息中心+打印机设置

**仓管US端**（4 Tab）
```
[ 工作台 ] [ 入库 ] [ 仓库 ] [ 我的 ]
```
- 工作台 = Web 的工作台（统计+待办+预警+任务进展+通知公告）

## 3. 起运国仓管端

> **核心理念**：仓管全程在仓库现场用 App 完成全部操作，不需要回办公室用电脑

### 3.0 完整仓库工作流

```
快递到仓 → ① 扫码入库 → ② 称重量方 → ③ 生成子运单 → ④ 打印面单
→ ⑤ 贴面单 → ⑥ 分配库位上架 → ⑦ 待装箱
→ ⑧ 扫码装箱 → ⑨ 封箱 → ⑩ 打印箱唛 → 等待发运
```

### 3.1 工作台

> 对应 Web：中国仓待办工作台

**顶部**
- 仓库名称（广州总仓）+ 切换按钮
- 蓝牙打印机状态（🟢已连接 / 🔴未连接）

**统计标签行**：待入库 N票 · 无订单快递 N · 退运待处理 N · 在库货件 N

**待办事项**（对应 Web 的6项待办）

| 待办 | 跳转 |
|------|------|
| 待入库运单 | 起运国仓储/快递入库 |
| 调拨到仓待处理 | 起运国仓储/调拨入库 |
| 已分配待装箱 | 起运国仓储/任务执行（集中装箱） |
| 无订单快递待处理 | 起运国仓储/无订单快递 |
| 退运单待处理 | 起运国仓储/退运处理 |
| 在库货件待处理 | 起运国仓储/库存列表 |

**预警消息**：库存异常等

**任务进展**：JOB 进度卡片

**底部快捷入口**（对应 Web 底部）：入库记录 · 集中装箱(海运) · 库存列表 · 无订单快递

### 3.2 扫码入库（核心页面）

> 对应 Web：起运国仓储/快递入库 Tab

**这是 App 最核心的页面**。仓管拿着手机+蓝牙打印机在货物旁完成全流程：

#### 3.2.1 扫描页

- 全屏相机 + 扫描框 + 闪光灯开关 + 手动输入切换
- 底部统计：今日已扫 N件 | 本批次 N件
- 底部最近记录：✅ SF12345 → MO-xxx 成功

#### 3.2.2 匹配成功 → 入库操作（一页完成）

**匹配信息**（绿色卡片）：运单号 · 客户 · 路线 · 收件人 · 应收件数/已入库件数 · 客户申报品名

**称重量方**

| 字段 | 控件 | 必填 | 说明 |
|------|------|------|------|
| 实际件数 | 步进器 | 是 | 默认1 |
| 实际重量(kg) | 数字键盘 | **是** | 称重后填入 |
| 长/宽/高(cm) | 数字键盘 | 否 | 量方后填入 |
| 体积重(kg) | 自动计算 | — | 长×宽×高÷6000 |
| **计费重量** | 自动计算 | — | max(实重,体积重)，**大字突出** |

**运费参考**：计费重量 × 单价 = ¥XXX（灰色信息条）

**包裹状况**：大按钮单选 ✅正常 / ⚠️破损 / 💧受潮 / 📦拆封 / ❌少件

**异常时**：必须拍照（≥1张，≤5张）+ 备注

**库位号**：Input（可扫库位二维码）

**底部按钮**
```
[ 确认入库并打印面单 ]  ← 蓝色大按钮（默认）
[ 仅入库不打印 ]        ← 灰色小按钮
```

#### 3.2.3 入库成功

1. 后端：创建入库记录 + 生成子运单号
2. 蓝牙打印面单（100×150mm热敏标签，含QR码/运单号/子单号/收件人/计费重量/运费/入仓号）
3. 震动+音效 → 0.5秒后自动返回扫描页

#### 3.2.4 匹配失败

三个按钮：登记无单快递 | 手动输入运单号 | 继续扫描

#### 3.2.5 异常处理

异常时自动推送通知到操作员(OPS_CN)+销售(SALES)，面单加印⚠️标记
