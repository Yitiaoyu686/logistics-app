## 1. 设计原则与定位

### 1.1 App 定位

App 定位为**现场操作工具**，面向在仓库、港口、配送现场工作的人员，聚焦以下场景：

- **扫码操作** — 入库扫描、库存盘点、装箱确认
- **状态更新** — 派送状态、物流节点、到货确认
- **数据采集** — 拍照上传（破损/签收）、重量录入、费用记录
- **信息查询** — 订单跟踪、库存查询、运价查询
- **消息接收** — 推送通知、待办提醒、预警信息

App **不承担**复杂的管理操作（订单创建/拆单、任务编排、财务对账、系统配置等），这些保留在 Web 端。

### 1.2 设计原则

| 原则 | 说明 |
|------|------|
| **单手操作** | 所有核心操作可单手完成（仓库场景另一手拿货） |
| **大按钮/大字体** | 关键操作按钮≥48px高度，列表字体≥14px |
| **离线优先** | 扫码、拍照等操作离线可执行，联网后自动同步 |
| **3步完成** | 核心操作（扫码→确认→提交）不超过3步 |
| **角色聚焦** | 每个角色只看到自己需要的功能，不做大而全 |
| **实时推送** | 关键状态变更通过推送通知到相关人员 |

### 1.3 与 Web 端的关系

```
┌─────────────────────────────────────────────────┐
│                    Web 端（全功能）                │
│  订单创建/拆单 · 任务编排 · 财务对账 · 系统配置        │
│  客户KYC · 经营分析 · 权限管理 · 报表导出            │
├─────────────────────────────────────────────────┤
│              共享后端 API + 数据库                  │
├─────────────────────────────────────────────────┤
│                   App 端（现场操作）                │
│  扫码入库 · 派送执行 · 签收确认 · 库存查询            │
│  订单跟踪 · 费用录入 · 运价查询 · 消息推送            │
└─────────────────────────────────────────────────┘
```

## 3. 仓管端（起运国）

> 角色：WAREHOUSE_CN
> 使用场景：广州总仓、深圳集货区、上海仓库

### 3.1 首页工作台

**布局**：顶部仓库选择器 + 今日统计卡片 + 快捷操作入口 + 待办列表

| 区域 | 内容 |
|------|------|
| 仓库选择 | 下拉切换当前操作仓库（广州总仓/深圳集货区） |
| 今日统计 | 今日入库数、今日件数、今日重量(kg)、异常待处理 |
| 快捷入口 | 扫码入库（大按钮）、库存查询、装箱指引、调拨管理 |
| 待办列表 | 待入库订单列表（按到货时间排序） |

### 3.2 扫码入库

> 核心高频操作，必须极致简化

**流程**：打开相机 → 扫描快递单条码 → 自动匹配订单 → 确认/补充信息 → 提交

**扫描页面**

| 元素 | 说明 |
|------|------|
| 相机取景框 | 全屏相机预览，中央对准框 |
| 手动输入 | 底部输入框，可手动输入快递单号 |
| 闪光灯按钮 | 仓库光线不足时开启 |
| 扫描历史 | 底部小字显示最近5条扫描记录 |

**匹配结果页**

| 场景 | 展示 | 操作 |
|------|------|------|
| 匹配成功 | 绿色提示 + 订单号/客户/路线/件数 | 确认入库 → 下一单 |
| 匹配失败 | 橙色提示"未找到订单" | 标记为无单快递 / 手动关联 |
| 包裹异常 | 选择异常类型 | 拍照上传 → 备注 → 提交 |

**异常类型选择**

| 类型 | 英文 | 说明 |
|------|------|------|
| 正常 | GOOD | 默认 |
| 破损 | DAMAGED | 外包装破损 |
| 受潮 | WET | 包装有水渍 |
| 拆封 | OPENED | 已被打开 |
| 少件 | INCOMPLETE | 数量不符 |

**拍照功能**
- 点击"拍照"按钮打开相机
- 可拍多张（最多5张）
- 自动压缩上传（长边≤1920px，质量80%）
- 照片关联到入库记录

### 3.3 库存查询

**列表页**

| 筛选条件 | 控件 |
|---------|------|
| 搜索 | 运单号/客户名/快递单号 |
| 库存状态 | 在库/已分配/已装箱/已发运 |
| 入库日期 | 日期范围 |

| 列表字段 | 说明 |
|---------|------|
| 运单号 | 点击进入详情 |
| 客户 | 客户简称 |
| 件数 | N件 |
| 重量 | N kg |
| 入库天数 | 滞留天数（超7天标红） |
| 状态 | 彩色标签 |

**详情页**
- 订单基本信息（运单号、客户、路线、服务类型）
- 包裹明细（快递单号、实重、体积重、状态）
- 入库记录（时间、操作人、异常备注、照片）
- 当前位置（货架号/库位）

### 3.4 装箱指引

> 辅助仓管确认货物装入正确的集装箱/托盘

**列表页** — 当前待装箱的集装箱/托盘列表

| 字段 | 说明 |
|------|------|
| 集装箱号 | 如 MSKU1234567 |
| 柜型 | 20GP/40GP/40HQ/45HQ |
| 路线 | 如 广州→拉各斯 |
| 已装/总件数 | 45/60 件 |
| 已装/总重 | 1200/1500 kg |
| 状态 | 装箱中/已封箱 |

**装箱详情页**
- 集装箱信息（箱号、柜型、路线、承运人）
- 已装订单列表（运单号、客户、件数、重量）
- 剩余容量（重量/体积百分比进度条）
- 操作按钮：扫码添加订单 | 封箱确认

### 3.5 调拨跟踪

**列表页** — 进行中的调拨单列表

| 字段 | 说明 |
|------|------|
| 调拨单号 | TRF-YYYYMMDD-NNN |
| 路线 | 深圳集货区 → 广州总仓 |
| 件数/重量 | N件 / N kg |
| 状态 | 待执行/运输中/已到达/已签收 |
| 发起时间 | YYYY-MM-DD HH:mm |

**详情页** — 调拨单详情 + 货物清单 + 状态时间线

## 11. 技术约束与离线策略

### 11.1 网络环境

| 地区 | 网络状况 | 策略 |
|------|---------|------|
| 中国仓库 | 4G/WiFi，稳定 | 实时同步 |
| 尼日利亚仓库 | 3G/4G，不稳定 | 离线队列 + 自动重试 |
| 配送途中 | 2G/3G，间歇断网 | 本地缓存 + 后台同步 |

### 11.2 离线操作队列

以下操作支持离线执行，联网后自动同步：

| 操作 | 离线行为 | 同步策略 |
|------|---------|---------|
| 扫码入库 | 本地存储扫描记录 | 联网后批量上传 |
| 拍照上传 | 照片存本地 | WiFi 下自动上传 |
| 签收确认 | 本地记录签收 | 联网后同步 + 推送 |
| 节点更新 | 本地记录 | 联网后同步 |
| 费用录入 | 本地草稿 | 联网后提交 |

离线状态下：
- 顶部显示"离线模式"横幅
- 操作记录标记"待同步"状态
- 联网后自动同步，冲突时以服务端为准

### 11.3 设备要求

| 项目 | 最低要求 |
|------|---------|
| 系统 | iOS 15+ / Android 10+ |
| 存储 | 200MB 可用空间 |
| 相机 | 后置相机（扫码+拍照） |
| 网络 | 支持 2G/3G/4G/WiFi |
| 定位 | GPS（派送导航用） |

### 11.4 安全要求

| 项目 | 说明 |
|------|------|
| 登录认证 | JWT Token + 刷新机制 |
| 数据传输 | HTTPS 加密 |
| 本地存储 | 敏感数据加密存储 |
| 会话超时 | 30天自动过期 |
| 权限控制 | 角色级别功能隔离 |

## 12. Web 与 App 功能分界

### 12.1 仅 Web 端（App 不做）

| 功能 | 原因 |
|------|------|
| 订单创建/拆单 | 多步骤复杂表单，需大屏操作 |
| 任务编排（起运国办/到达国办） | 多面板复杂工作流，~2500行组件 |
| 客户 KYC（企业资质） | 文档上传+复杂表单 |
| 财务对账 | 多维度交叉核对 |
| 提成/薪资计算 | 复杂计算规则 |
| 经营分析仪表盘 | 大屏图表交互 |
| 系统管理全部 | 管理员专用 |
| 应收应付管理 | 复杂财务流程 |
| 成本审计 | 多层级审批 |

### 12.2 Web + App 都有（App 为简化版）

| 功能 | Web 版本 | App 版本 |
|------|---------|---------|
| 订单跟踪 | 完整列表+筛选+详情 | 简化列表+详情（只读） |
| 库存查询 | 完整列表+批量操作 | 搜索+查看（只读） |
| 费用录入 | 完整表单+批量 | 单笔快速录入 |
| DPN管理 | 创建+分配+跟踪+成本 | 列表查看+分配司机 |
| 消息通知 | 发布+模板管理 | 接收+查看 |

### 12.3 仅 App 端（Web 没有）

| 功能 | 说明 |
|------|------|
| 条码扫描 | 调用手机相机扫描快递单/集装箱条码 |
| GPS 定位 | 派送路线导航、位置打卡 |
| 拍照签收 | 现场拍照作为签收凭证 |
| 电话拨号 | 一键拨打客户/司机电话 |
| 地图导航 | 跳转第三方地图导航 |
