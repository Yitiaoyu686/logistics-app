## 1. 状态枚举定义

### 1.1 MasterOrderStatus（主订单状态）

| 枚举值 | 中文名称 | 标签颜色 | 说明 |
|--------|---------|---------|------|
| `PENDING_INBOUND` | 等待入库 | warning | 订单已创建，等待货物入库 |
| `INBOUND` | 已入库 | cyan | 货物已入库 |
| `PENDING_DEPARTURE` | 等待发货 | orange | 已打包待发运 |
| `DEPARTED` | 已发运 | blue | 货物已发运 |
| `IN_TRANSIT` | 运输中 | geekblue | 货物运输途中 |
| `ARRIVED` | 已到达 | purple | 货物到达目的港/站 |
| `PARTIAL_DELIVERED` | 部分签收 | lime | 部分子单已签收 |
| `COMPLETED` | 已完成 | success | 全部签收完成 |
| `EXCEPTION` | 异常 | error | 订单出现异常 |
| `RETURN_APPLIED` | 退单申请中 | volcano | 已提交退单申请 |
| `SUSPENDED` | 已暂停 | red | 订单被挂起 |
| `CANCELLED` | 已取消 | default | 订单已取消 |

### 1.2 SubOrderStatus（子订单状态）

| 枚举值 | 中文名称 | 说明 |
|--------|---------|------|
| `PENDING_INBOUND` | 等待入库 | 子单创建，待入库 |
| `INBOUND` | 已入库 | 货物已入库 |
| `PENDING_PACKING` | 待打包 | 等待打包 |
| `PACKED` | 已打包 | 打包完成 |
| `PENDING_DEPARTURE` | 等待发货 | 待发运 |
| `IN_TRANSIT` | 运输中 | 运输途中 |
| `CUSTOMS_CLEARANCE` | 清关中 | 海关清关 |
| `ARRIVED` | 已到达 | 到达目的地 |
| `PENDING_DELIVERY` | 待配送 | 等待末端配送 |
| `DELIVERING` | 配送中 | 末端配送中 |
| `DELIVERED` | 已签收 | 签收完成 |
| `EXCEPTION` | 异常 | 出现异常 |
| `RETURN_APPLIED` | 退单申请中 | 退单申请 |
| `SUSPENDED` | 已暂停 | 挂起 |
| `CANCELLED` | 已取消 | 已取消 |

### 1.3 paymentStatus（支付状态）

| 枚举值 | 中文名称 | 说明 |
|--------|---------|------|
| `UNPAID` | 未付 | 尚未支付任何款项 |
| `PARTIAL` | 部分付 | 已支付部分款项 |
| `PAID` | 已付 | 全额已支付 |

### 1.4 paymentMethod（支付方式）

| 枚举值 | 中文名称 | 说明 |
|--------|---------|------|
| `PREPAID` | 预付 | 发货前付款 |
| `COD` | 到付 | 货到付款 |
| `CREDIT_CARD` | 信用卡 | 信用卡支付 |

### 1.5 transportType（运输方式）

| 枚举值 | 中文名称 | 说明 |
|--------|---------|------|
| `SEA` | 海运 | 海运运输 |
| `AIR` | 空运 | 空运运输 |

### 1.6 serviceType（服务类型）

| 枚举值 | 中文名称 | 对应运输方式 |
|--------|---------|-------------|
| `STANDARD_AIR` | 普快空运 | AIR |
| `EXPRESS_AIR` | 特快空运 | AIR |

### 1.7 cargoType（货物类型）

| 枚举值 | 中文名称 | 说明 |
|--------|---------|------|
| `GENERAL` | 普货 | 普通货物 |
| `SENSITIVE` | 非普货 | 敏感货物/特殊货物 |

### 1.8 ExpressPackage.status（快递包裹状态）

| 枚举值 | 中文名称 | 说明 |
|--------|---------|------|
| `PENDING` | 待收货 | 快递包裹待收货 |
| `RECEIVED` | 已收货 | 已收到快递包裹 |

### 1.9 splitStatus（拆单状态）

| 枚举值 | 中文名称 | 说明 |
|--------|---------|------|
| `PENDING` | 待拆分 | 尚未拆分 |
| `PARTIAL` | 部分拆分 | 部分物品已分配 |

### 1.10 exportMode（出口方式）

| 枚举值 | 中文名称 | 说明 |
|--------|---------|------|
| `BUYER_EXPORT` | 买单出口 | 使用买单报关 |
| `SELF_DOCS_EXPORT` | 自备单证出口 | 使用自有单证报关 |

### 1.11 deliveryMethod（配送方式）

| 枚举值 | 中文名称 | 说明 |
|--------|---------|------|
| `DELIVERY` | 配送 | 送货上门 |
| `PICKUP` | 自提 | 客户自提 |

### 1.12 currency（币种）

| 枚举值 | 中文名称 | 说明 |
|--------|---------|------|
| `CNY` | 人民币 | 中国人民币 |
| `USD` | 美元 | 美国美元 |
| `NGN` | 奈拉 | 尼日利亚奈拉 |

### 1.13 returnType（退单类型）

| 枚举值 | 中文名称 | 说明 |
|--------|---------|------|
| `CUSTOMER_CANCEL` | 客户主动取消 | 客户主动申请取消 |
| `GOODS_ISSUE` | 货物问题 | 货物质量或数量问题 |
| `ADDRESS_ERROR` | 地址错误 | 收货地址信息有误 |
| `OTHER` | 其他 | 其他原因 |

### 1.14 returnRefundMethod（退款方式）

| 枚举值 | 中文名称 | 说明 |
|--------|---------|------|
| `ORIGINAL` | 原路退回 | 按原支付方式退回 |
| `BANK_TRANSFER` | 银行转账 | 银行转账退款 |
| `OFFLINE` | 线下退款 | 线下退款处理 |

### 1.15 LogisticsStep（物流节点）

| 步骤顺序 | 枚举值 | 中文名称 |
|---------|--------|---------|
| 1 | `INBOUND` | 入库 |

| 4 | `CONTAINER_LOADING` | 装柜 |
| 5 | `OUTBOUND` | 出库 |
| 6 | `EXPORT_CUSTOMS` | 出口报关 |
| 7 | `DEPARTED` | 已发运 |
| 8 | `IN_TRANSIT` | 运输中 |
| 9 | `ARRIVED_PORT` | 到达港口 |
| 10 | `IMPORT_CUSTOMS` | 进口清关 |
| 11 | `WAREHOUSE_IN` | 入仓 |
| 12 | `DELIVERY_DISPATCH` | 配送派发 |
| 13 | `DELIVERED` | 已签收 |

## 2. 新建订单表单

### 2.1 组件信息

| 属性 | 值 |
|------|-----|
| 组件文件 | OrderCreate.tsx |
| 页面类型 | 独立页面/Modal |

### 2.2 基础信息区块

| 字段名 | 标签 | 组件 | 必填 | 默认值 | 说明 |
|--------|------|------|------|--------|------|
| `clientCode` | 客户 | Select（搜索模式） | 是 | - | 支持按客户名称/编号搜索，选择后自动填充客户相关信息 |
| `serviceType` | 服务类型 | Select | 是 | - | 按运输方式过滤可选项（空运: STANDARD_AIR/EXPRESS_AIR，海运: LCL_SEA/FCL_SEA） |
| `warehouseEntryNo` | 入仓号 | Input（只读） | - | 自动生成 | 选择客户后自动生成，不可手动编辑 |
| `exportMode` | 出口方式 | Select | 否 | - | BUYER_EXPORT / SELF_DOCS_EXPORT |
| `paymentMethod` | 支付方式 | Select | 否 | PREPAID | 默认预付 |
| `deliveryMethod` | 配送方式 | Select | 否 | - | DELIVERY / PICKUP |
| `transportType` | 运输方式 | hidden | - | 由业务线决定 | 根据 serviceType 自动确定，不展示 |
| `routeCode` | 路线代码 | hidden | - | - | 隐藏字段，由系统自动设置 |
| `salesPerson` | 业务员 | hidden | - | 张业务 | 默认当前业务员，隐藏不展示 |
| `currency` | 币种 | hidden | - | CNY | 默认人民币，隐藏不展示 |

### 2.3 发货信息区块

| 字段名 | 标签 | 组件 | 必填 | 说明 |
|--------|------|------|------|------|
| `senderName` | 发货人姓名 | Input | 是 | - |
| `senderPhone` | 发货人电话 | Input | 是 | - |
| `senderAddress` | 发货人地址 | Input | 是 | - |

**业务规则：**
- 支持从客户发货人列表快速选择，自动填充发货人信息

### 2.4 收货信息区块（Form.List 多收件人）

| 字段名 | 标签 | 组件 | 必填 | 说明 |
|--------|------|------|------|------|
| `receivers[N].consigneeName` | 收件人姓名 | Input | 是 | - |
| `receivers[N].consigneePhone` | 收件人电话 | Input | 是 | - |
| `receivers[N].destCountry` | 目的国家 | Select | 是 | - |
| `receivers[N].destCity` | 目的城市 | Input | 否 | - |
| `receivers[N].consigneeState` | 州/省 | Input | 否 | - |
| `receivers[N].consigneeZipCode` | 邮编 | Input | 否 | - |
| `receivers[N].consigneeAddress` | 收件地址 | Input | 是 | - |
| `receivers[N].consigneeEmail` | 邮箱 | Input | 否 | - |

**业务规则：**
- 使用 Form.List 实现多收件人
- 支持动态添加/删除收件人
- 每个收件人至少填写姓名、电话、目的国家、地址

### 2.5 包裹明细区块（Form.List）

| 字段名 | 标签 | 组件 | 必填 | 说明 |
|--------|------|------|------|------|
| `expressPackages[N].courier` | 快递公司 | Select | 否 | 下拉选择快递公司 |
| `expressPackages[N].trackingNo` | 快递单号 | Input | 否 | - |
| `expressPackages[N].itemName` | 品名 | Input | 否 | - |
| `expressPackages[N].cargoType` | 货物类型 | Select | 否 | GENERAL / SENSITIVE |
| `expressPackages[N].weight` | 重量 | InputNumber | 否 | 单位：kg |
| `expressPackages[N].pieces` | 件数 | InputNumber | 否 | - |
| `expressPackages[N].declaredValue` | 申报价值 | InputNumber | 否 | - |

### 2.6 智能粘贴导入

**功能说明：**
- 支持从剪贴板批量粘贴快递包裹信息
- 每行一条记录，格式：`快递公司 运单号 品名 件数 重量`
- 粘贴后自动解析并填入 Form.List
- 实时显示统计信息：合计件数、合计重量

### 2.7 预估运费计算

| 运输方式 | 计算公式 |
|---------|---------|
| 空运（AIR） | 总重量 × 55元/kg + 100元 |
| 海运（SEA） | 总重量 × 12元/kg + 100元 |

### 2.8 备注区块

| 字段名 | 标签 | 组件 | 必填 | 说明 |
|--------|------|------|------|------|
| `remarkTags` | 备注标签 | Select（多选） | 否 | 可选标签：无电池、加急处理、易碎品 |
| `remarkCustom` | 自定义备注 | TextArea | 否 | 最多120字 |

根据 entityType 展示不同布局：

**COMPANY_CN（中国企业）：**

公司名称、所在国家、注册号、税号（TIN）、负责人、自定义字段、银行信息

**INDIVIDUAL（个人）：**
真实姓名、证件类型、证件号码、联系电话、联系邮箱、银行信息

#### 区块6：订单初始信息

#### 区块7：订单实际信息

实际入库物品清单

#### 区块8：应收明细

- 多币种分组展示（CNY / USD / NGN）
- 费用归属选择功能
- 费用项目明细

## 9. 挂起与恢复

### 9.1 暂停 Modal

| 字段名 | 标签 | 组件 | 必填 | 说明 |
|--------|------|------|------|------|
| 暂停原因 | 暂停原因 | Select | 是 | 见下方选项 |
| 备注 | 备注 | TextArea | 否 | 补充说明 |

**暂停原因选项：**

| 选项 | 说明 |
|------|------|
| 客户要求 | 客户主动要求暂停 |
| 付款问题 | 付款未到账或有争议 |
| 海关查验 | 海关抽查 |
| 单证不齐 | 报关单证不齐全 |
| 货物问题 | 货物损坏/短缺等 |
| 内部调度 | 公司内部调度原因 |
| 其他 | 其他原因 |

### 9.2 暂停数据存储

```
存储位置：localStorage['order_suspend_store']
数据结构：{
  [orderId]: {
    originalStatus: string,    // 暂停前的原始状态
    reason: string,            // 暂停原因
    suspendedAt: datetime      // 暂停时间
  }
}
```

### 9.3 恢复逻辑

1. 从 `localStorage['order_suspend_store']` 读取对应 orderId 的记录
2. 获取 `originalStatus`（暂停前状态）
3. 将订单状态恢复为 `originalStatus`
4. 若无记录，默认恢复为 `PENDING_INBOUND`
5. 清除 localStorage 中该订单的暂停记录

## 10. 退单流程

### 10.1 申请退单

**提交字段：**

| 字段名 | 说明 |
|--------|------|
| `returnType` | 退单类型（CUSTOMER_CANCEL/GOODS_ISSUE/ADDRESS_ERROR/OTHER） |
| `returnReason` | 退单原因（详细描述） |
| `returnRefundAmount` | 退款金额 |
| `returnRefundMethod` | 退款方式（ORIGINAL/BANK_TRANSFER/OFFLINE） |
| `needReturn` | 是否需要退运货物 |
| `returnShippingNote` | 退运备注 |

**提交后：** 订单状态变更为 `RETURN_APPLIED`

### 10.2 审核通过

调用 `approveReturn` API，系统自动执行以下联动操作：

| 步骤 | 操作 | 说明 |
|------|------|------|
| 1 | 取消子订单 | 将所有关联子订单状态设为 CANCELLED |
| 2 | 生成退运记录 | 如需退运，生成退运物流记录 |
| 3 | 更新库存 | 释放相关库存 |
| 4 | 重算集装箱 | 重新计算受影响集装箱的容量 |
| 5 | 取消待审费用 | 取消该订单的待审核费用项 |
| 6 | 删除待配送单 | 删除末端配送相关记录 |

**审核通过后：** 订单状态变更为 `CANCELLED`

### 10.3 审核驳回

| 字段 | 说明 |
|------|------|
| `rejectReason` | 驳回原因（必填） |

**驳回后：** 订单状态恢复为 `previousStatus`（申请退单前的状态）
