## 1. 系统定位

跨境物流全链路管理平台（TMS/ERP），面向 **中国 → 非洲（尼日利亚/加纳）** 方向的海运/空运货代公司内部运营团队。

**当前定位**: 产品经理需求 Demo 原型，后端 Express + SQLite 已连通，前端通过 axios 调用 REST API。

### 2.3 认证流程

```mermaid

    前端->>前端: localStorage.removeItem('token'/'user')
    前端->>前端: 重定向至登录页
```

### 6.2 订单生命周期（从创建到签收）

```mermaid
sequenceDiagram
    participant 销售 as 销售(SALES)
    participant OMS as 订单中心
    participant 起运仓 as 起运国仓库
    participant 起运操作 as 起运国操作
    participant 运输 as 国际运输
    participant 到达操作 as 到达国操作
    participant 到达仓 as 到达国仓库
    participant 客户 as 终端客户

    销售->>OMS: 创建订单(客户+收发货人+包裹)
    OMS->>OMS: 生成主单号 + 自动拆分子单
    OMS-->>销售: 订单创建成功

    Note over 起运仓: 快递到仓
    起运仓->>起运仓: 扫码入库(匹配订单运单)
    起运仓->>起运仓: 称重量方 → 更新库存
    起运仓->>起运仓: 任务执行(海运装集装箱/空运装集装号)(按线路分组)
    起运仓->>起运仓: 封箱 → 绑定JOB任务

    起运操作->>起运操作: 创建运输任务(JOB)
    
    Note over 起运仓,起运操作: 仓库"执行任务" = 出库发运，JOB状态→已发运
    起运仓->>起运操作: 执行任务(出库发运)
    起运操作->>起运操作: 节点更新: 已离库→出口报关→海关放行→已起运
    起运操作->>起运操作: 录入JOB成本(起运国)

    Note over 运输: 海运/空运在途
    运输-->>到达操作: 到港

    到达操作->>到达操作: 节点更新: 已到港→进口申报→进口放行→到达入仓
    到达操作->>到达操作: 录入JOB成本(到达国)

    Note over 到达仓: 清关放行后，按JOB入库（唯一入库途径）
    到达仓->>到达仓: 任务入库(按JOB，扫描集装箱号→逐单核收)
    到达仓->>到达仓: 入库后进入库存

    alt 本站配送/自提（无需转运）
        到达仓->>客户: 直接配送上门 或 通知自提
        客户-->>到达仓: 签收/核销
    else 需要转运到其他站点（DPN站点调拨）
        到达仓->>到达仓: 创建DPN(主仓→卫星站，如拉各斯→伊巴丹)
        到达仓->>到达仓: DPN绑定运单 → 执行发车(司机/车牌)
        Note over 到达仓: DPN运输中 → 到达卫星站
        到达仓->>到达仓: 卫星站DPN入库(接收货物)
        到达仓->>客户: 从卫星站配送上门 或 通知自提
        客户-->>到达仓: 签收/核销
    end
```

### 10.3 毛利计算公式

```
毛利 = 应收合计 - 总成本
毛利率 = 毛利 / 应收合计 × 100%

应收合计 = 运费(RMB) + 到付收入(USD×汇率) + 其他应收
总成本 = 起运国成本合计 + 到达国成本合计(外币×汇率)
起运国成本 = 运费 + 提货费 + 送货费 + 包装费 + 垫付运费
到达国成本 = 清关费 + 到门费 + 转运费 (USD/NGN→CNY)
```
