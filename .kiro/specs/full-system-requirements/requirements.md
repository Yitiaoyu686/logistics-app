# 喵喵国际物流管理系统 - 完整需求规格说明书

## 项目描述

基于当前 Web 端已实现页面的逐一梳理，覆盖全部模块、页面、交互逻辑和数据字段，作为后续开发的完整依据。

---

## 一、全局架构

### 1.1 导航体系

- **顶部域切换栏**: 综合协同 / 海运业务 / 空运业务 / 系统管理，四域切换
- **左侧深色菜单**: 根据当前域 + 当前角色动态过滤显示
- **面包屑导航**: 首页 > 域名 > 模块名
- **卡片式 Tab 页签**: 模块内子页面切换
- **右上角**: 角色名称 + 仓库选择器(全部仓库下拉) + 角色标签 + 头像

### 1.2 角色权限体系

| 角色编码 | 角色名称 | 站点范围 | 可见域 |
|---------|---------|---------|------|
| ADMIN | 系统管理员 | 全站点 | 全部 |
| SALES | 销售人员 | 分配站点 | 海运/空运 |
| WAREHOUSE_CN | 起运国仓管 | 分配站点 | 海运/空运 |
| OPS_CN | 起运国操作 | 分配站点 | 海运/空运 |
| OPS_US | 到达国操作 | 分配站点 | 海运/空运 |
| WAREHOUSE_US | 到达国仓管 | 分配站点 | 海运/空运 |
| FINANCE | 财务人员 | 分配站点 | 综合协同 |
| BOSS | 管理层 | 全站点 | 综合协同 |
| DRIVER | 司机 | 分配站点 | - |

### 1.3 业务域模型

- **综合协同 (ALL)**: 工作台、财务中心、经营分析 → FINANCE / ADMIN / BOSS
- **海运业务 (SEA)**: 客户/订单/起运仓/起运办/到达办/到达仓 → 业务角色
- **空运业务 (AIR)**: 同海运模块，数据按空运筛选
- **系统管理 (SYS)**: 全部设置页 → ADMIN

### 1.4 认证与登录

- JWT Token 认证，localStorage 持久化
- 登录页：用户名 + 密码
- 退出登录：清除 token/user，重定向登录页
- ngrok 环境自动清除本地存储

## 二、工作台 (Dashboard)

### 2.1 管理员工作台

**所属域**: 综合协同 / 海运 / 空运（三域共享，内容一致）

**快捷入口标签**: 账号总数 N个 / 角色管理入口 N个 / 权限配置入口 N个 / 流程管理入口 N个（可点击直达）

- 示例：用户账号管理(10)、角色管理(1)、审批流程维护(1)

- 暂无预警时显示空状态图标
- 有预警时列表展示

#### 通知公告卡片
- 列表：标题（重要公告带红点标记）+ 发布时间

#### 底部快捷导航
- 横向链接列表：→ 用户管理 / → 角色管理 / → 权限配置 / → 流程管理

## 十二、通用交互模式

### 12.1 列表页标准模式
1. **统计卡片区**: 顶部彩色数字统计
2. **搜索/筛选工具栏**: 搜索框 + 多个下拉筛选 + 查询/重置按钮 + 主操作按钮(右侧)
3. **数据表格**: Ant Design Table 组件，支持排序↕ / 分页(底部)
4. **操作列**: 蓝色文字链接（详情/编辑/删除等）

### 12.2 详情页标准模式
- **Drawer 抽屉**: 从右侧滑出，左侧锚点导航 + 右侧Card区域滚动
- **或 Modal 弹窗**: 表单编辑场景

### 12.3 状态标签系统
- 蓝色标签：信息类（海运/空运/特快/子单/主单）
- 绿色标签：成功/完成（已审核/启用/已签收）
- 橙色标签：警告/进行中（待审批/特快）
- 红色标签/文字：异常/危险（逾期/驳回/删除）

### 12.4 费用审核流程
统一三级审核：**草稿 → 待审核/待主管审核 → 已审核/驳回**
- 草稿可编辑/删除
- 已审核条目不可直接修改，需申请变更后重新审核

### 12.5 多币种处理
- 支持 USD / CNY / NGN / GHS 四种货币
- 汇率自动折算为 CNY 显示
- 费用明细按币种分组展示

### 12.6 挂起/恢复功能
- 订单和任务均支持挂起(暂停)操作
- 挂起时弹出 Modal 选择暂停原因
- 已挂起状态：列表显示"已暂停"标签，操作按钮变为"恢复"，其他操作禁用
