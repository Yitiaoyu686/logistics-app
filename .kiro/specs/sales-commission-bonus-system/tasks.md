- [x] 1. 创建提成计算工具库
- [x] 1.1 实现类型体系和方案一ABCD双指标互锁计算
  - 创建提成计算工具文件，定义方案类型枚举（PLAN_A_ABCD、PLAN_B_SEA_VETERAN、PLAN_C_NIGERIA_SEA、PLAN_D_NIGERIA_AIR）和币种类型（CNY、NGN）
  - 定义全部配置接口：ABCD阶梯配置（含每级最低票数、毛利上限、每票单价、毛利提成比例）、海运老员工配置、尼日利亚海运配置、尼日利亚空运配置、彩蛋奖金配置
  - 定义月度业绩数据接口（员工ID、月份、总票数、总毛利、总体积、总重量、海运毛利、空运毛利、应收款状态）和各方案计算结果接口
  - 定义默认方案一配置常量：基本任务50票、工资倍数3、四个阶梯（A: ≥50票/毛利≤15000/3元每票/15%毛利，B: ≥200票/≤30000/5元/20%，C: ≥350票/≤100000/8元/25%，D: ≥500票/>100000/13元/35%）
  - 实现方案一计算函数：先判断基本任务是否达标（票数≥50且毛利>基数），再从D向A逐级降级匹配（双指标同时满足），计算每票提成+毛利提成，返回命中等级和降级标记
  - _Requirements: 1.1, 1.2, 1.3, 1.4, 1.5, 1.6_

- [x] 1.2 (P) 实现方案二、方案三、方案四计算函数
  - 定义默认方案二配置常量：基本任务6000元、分段点35000元、低段40%、高段50%
  - 实现方案二计算函数：毛利6千~3.5万按40%，超3.5万部分按50%分段计算；不足基本任务时从空运提成补足差额；返回海运提成、空运补足金额和总提成
  - 定义默认方案三配置常量：基本任务30m³、三个阶梯（30-100m³ NGN 5000、100-200m³ NGN 9000、200+m³ NGN 15000）
  - 实现方案三计算函数：按分段阶梯累进计算体积奖金（而非全量匹配），未达30m³返回不合格，以NGN为币种返回各阶梯分段明细
  - 定义默认方案四配置常量：基本任务1000kg、三个阶梯（A: ≤2500kg/NGN 120每kg，B: ≤4500kg/NGN 150，C: ≤7500kg/NGN 200）
  - 实现方案四计算函数：超出基本任务的重量按最高匹配阶梯单价计算，未达1000kg返回不合格，以NGN为币种返回命中阶梯和超出重量
  - _Requirements: 2.1, 2.2, 2.3, 2.4, 2.5, 2.6, 3.1, 3.2, 3.3, 3.4, 3.5, 4.1, 4.2, 4.3, 4.4, 4.5, 4.6_

- [x] 1.3 (P) 实现彩蛋奖金、应收款校验、坏账扣减和绩效追踪
  - 定义默认彩蛋奖金配置常量：触发重量40000kg、奖金总额15000元、最低个人贡献2000kg、最低达标人数2人
  - 实现彩蛋奖金计算函数：接收团队全员月度业绩数组，判断团队总重量是否≥40吨，筛选个人重量≥2000kg的合格成员，合格人数<2则奖金无效，否则按个人重量占合格总重量比例分配15000元
  - 实现应收款校验过滤函数：遍历月度JOB数据，排除应收款未全部回收的订单，返回过滤后的有效业绩和被排除订单数量
  - 实现坏账扣减函数：从奖金中扣除坏账金额，不足时计算递延余额，返回原始金额、扣减金额、递延金额和最终实发金额
  - 实现绩效追踪函数：接收员工历史月度达标记录数组，计算连续达标/未达标月数，返回建议标签（连续3月达标→加薪，连续3月未达→减薪，连续5月未达→辞退）
  - _Requirements: 5.1, 5.2, 5.3, 5.4, 5.5, 6.1, 6.2, 6.3, 7.1, 7.3, 7.4, 7.5, 7.6, 8.1, 8.2, 8.3, 8.4_
