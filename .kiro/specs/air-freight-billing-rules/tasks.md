## Tasks

- [x] 1. 创建计费逻辑工具库
- [x] 1.1 实现计费类型体系和空运基础计算函数
  - 创建计费工具文件，定义货物品类枚举（普货、带电、带磁、食品、化妆品、化工品、药品、保健品、手机）和附加费率映射类型
  - 定义续重阶梯、空运配置、海运拼箱配置、文件寄送配置等全部接口类型和计算结果类型
  - 定义默认空运配置常量：体积除数6000、首重单价63元、续重阶梯（≥1kg 60元、≥5kg 57元、≥20kg 55元）、品类附加费率（10%~60%）、包装费2元/kg
  - 实现计费重量判定函数：比较实际毛重和体积重量（长×宽×高÷6000）取较大值；任一尺寸缺失时仅按实际毛重计费，返回 ACTUAL_ONLY 标识
  - 实现进位规则函数：首重1kg按整公斤进位，续重部分不足0.5kg按0.5计、超0.5不足1按1计
  - 返回结构化结果对象，包含原始重量、进位后重量、首重和续重拆分
  - _Requirements: 1.1, 1.2, 1.3, 2.1, 2.2, 2.3_

- [x] 1.2 实现完整空运运费计算链路
  - 实现首重续重阶梯计费：首重1kg×首重单价单独计费；续重按总重量找到最后一个 minWeight ≤ 续重的区间，整段按该区间单价计算
  - 实现混装品类解析函数：多品类取附加费率最高的品类作为计费标准；仅含普货时附加费率为0
  - 实现附加费计算：附加费 = 基础运费（首重费 + 续重费）× 最高附加费率
  - 实现包装附加费计算：勾选木箱包装时，包装费 = 计费重量 × 包装单价（2元/kg），与品类附加费独立计算
  - 整合完整空运运费计算函数：计费重量判定→进位→首重续重阶梯→附加费→包装费→总运费，所有金额保留2位小数
  - 返回完整计费明细对象，包含各步骤中间结果、命中阶梯索引、混装标记等
  - _Requirements: 3.1, 3.2, 3.3, 3.4, 4.1, 4.2, 4.3, 5.1, 5.2, 5.3, 6.1, 6.2, 6.3, 6.4_

- [x] 1.3 实现海运拼箱和文件寄送计费
  - 实现海运拼箱计费函数：计算货物密度（毛重÷体积），判定轻货（密度≤700）或重货（>700）；轻货按实际体积、重货按换算体积（毛重÷700）计费；最终取实际体积与换算体积较大值
  - 定义海运拼箱默认配置（换算标准1m³=700kg）和文件寄送默认配置（预付150元、到付21美元、限重0.5kg）
  - 实现文件寄送费用计算函数：预付返回CNY 150元、到付返回USD 21美元；重量超0.5kg时标记 overweight 警告
  - 海运拼箱返回结果包含实际体积、换算体积、密度、轻重货判定和最终计费体积
  - _Requirements: 7.1, 7.2, 7.3, 7.4, 7.5, 10.1, 10.2, 10.3_
